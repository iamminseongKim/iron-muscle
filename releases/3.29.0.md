# v3.29.0

## 최신 업데이트 핵심 요약
- 총 운동 시간 일시정지 시 화면 전체를 잠그고 시간·완료 세트를 표시합니다. 1.5초 길게 눌러 잠금을 해제하고 운동을 재개합니다.
- 휴식 타이머를 실제 경과 시간 기준으로 보정하고 복귀 시 즉시 갱신합니다. 완료음 반복 재생을 막고 Android/iOS 로컬 알림 예약·취소를 연동합니다.
- 마지막 세트 완료 시 종목 전환 휴식 안내, 60초 추가, 다음 종목으로 이동 또는 종목 추가를 제공합니다. 타이머를 최소화해도 계속 동작합니다.
- 세트 체크 해제 시 타이머가 열리는 문제를 수정하고 미사용 구형 타이머를 제거했습니다. 운동 취소 시 삭제 범위와 복구 불가 안내를 명확히 했습니다.
- 신규 UI와 알림 문구를 한국어·영어·일본어·중국어 간체/번체·스페인어·프랑스어·독일어에 반영했습니다.

## 검증 및 한계
- `npm test`: 18개 전체 테스트 스위트 통과. `npm run build`: TypeScript·Vite·모델 최적화 통과 (기존 대형 번들 경고 유지).
- 11개 신규 UI 키의 8개 언어 동기화 및 Android/iOS Capacitor 플러그인 동기화 확인.
- 모바일 브라우저 자동 검증: 일시정지 중 시간 고정, 짧은 탭 잠금 유지, 길게 눌러 해제, 마지막 세트 안내, 60초 추가, 종목 이동·추가, 체크 해제, 백그라운드 복귀 시 보정 및 완료음 1회 재생 확인.
- 기존 18개 테스트 스위트에 실제 휴식 시계의 백그라운드 시간 보정·일시정지·재개 및 권한 요청 중 알림 취소 경합 검증을 추가했습니다.
- 브라우저에서는 화면 복귀 시 시간 보정과 완료음으로 폴백합니다. 브라우저가 중단된 동안 OS 알림은 보장하지 않습니다.
- 네이티브 알림은 사용자 알림 권한, Android 정확한 알람 설정 및 OS 절전/방해 금지 정책에 영향을 받습니다. 화면 꺼짐 상태의 소리·진동은 실제 Android/iOS 기기에서 별도 확인이 필요합니다.
- iOS 릴리즈 산출물은 기존 워크플로에 따라 서명되지 않은 IPA입니다.

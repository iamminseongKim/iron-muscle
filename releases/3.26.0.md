# v3.26.0

## 최신 업데이트 핵심 요약
- 운동 인증샷 문구를 기존 6개에서 총 21개로 확장했습니다. 일반 응원 문구 10개, 로니 콜먼 3개, 톰 플라츠 2개를 추가했습니다.
- 문구 목록에서 직접 선택하거나 랜덤으로 바꿀 수 있습니다. 랜덤 선택은 직전 문구를 제외하며, 직접 입력도 유지합니다.
- 선수 명언은 인증샷에 선수 이름을 함께 표시하고, 편집 화면에서 출처를 열 수 있습니다. 문구를 직접 수정하면 원문과 일치하는 경우에만 선수 이름을 표시합니다.
- 추가 문구·명언·UI를 한국어, 영어, 일본어, 중국어 간체/번체, 스페인어, 프랑스어, 독일어에 반영했습니다.
- 인증샷 편집 시 해부도 디코딩을 재사용하고 150ms 동안 이어지는 입력을 모아 렌더링합니다. 이전 미리보기는 유지하며 새 이미지가 준비될 때까지 저장을 비활성화합니다.

## 3.25.0 점검 및 수정
- 운동 선택창의 조건부 반환 뒤에 실행되던 React 훅을 이동해 창을 닫았다 다시 열 때 훅 순서가 바뀌는 오류를 수정했습니다.
- 머신 변경과 과거 기록 복사 시 kg/lbs 중량을 환산합니다. 기존 앱의 0.5 단위 반올림 규칙을 따릅니다.
- 헬스장과 머신 설정 ID를 운동 기록에 보관해 같은 브랜드의 여러 머신을 구분합니다. 세션 병합에서도 다른 머신의 기록을 분리합니다.
- 완료한 세트가 있으면 빠른 머신 전환을 잠그고 별도 종목 추가로 기록하도록 안내합니다. 완료된 기록의 머신 정보를 덮어쓰지 않습니다.
- 과거 머신 ID가 없는 기록은 그대로 보존합니다. 머신 ID를 지정해 조회할 때 출처를 확정할 수 없는 구버전 기록을 자동 복사하지 않습니다.
- 다른 머신에 없는 의자 설정이 이전 머신에서 남는 문제, 헬스장 변경 이벤트를 단일 프로필로 잘못 해석하던 문제를 수정했습니다.
- 브랜드 자동 지정 제거, 머신 선택창의 Escape·포커스 이동·스크롤 개선, 헬스장 장비 검색에 전체 언어 번역 색인 적용. 영문 등에 한국어 수량 접미사가 노출되던 빈 번역을 문장 단위 번역으로 교체.

## 용량 및 최적화
- 모든 언어 팩에 동일하게 존재하는 구형 번역 599개를 제거했습니다. 기존 UI 번역 4,824개 조합의 표시 결과가 동일함을 비교했습니다.
- 동일 환경의 프로덕션 메인 JS는 3,115.59KB → 3,021.32KB, gzip 기준 1,016.39KB → 965.47KB입니다. 추가 기능을 포함한 결과이며 APK 설치 크기의 감소율을 뜻하지 않습니다.
- 최종 모델 압축에서 삭제되던 임시 gzip 생성 작업을 제거했습니다. 3D 모델의 기존 무손실 meshopt 압축과 형상 검증은 유지합니다.

## 검증 및 한계
- npm test, npm run build: 운동 기록·세션 병합·백업·언어 팩·신규 머신 회귀 테스트와 TypeScript/Vite/3D 모델 검증.
- Chrome 모바일 UI: 선택창 재열기, 중첩 Escape, 동일 브랜드 머신 구분, 완료 세트 보호, 문구 목록·랜덤 선택·출처, 320/390/768px 가로 넘침 확인.
- 21개 문구 전체에 대해 8개 언어 PNG 생성, 선수 이름, 텍스트 경계 및 60자 입력 제한 확인.
- 실제 Android/iOS 기기에서 사진 선택·저장·공유와 터치 지연은 검증하지 않았습니다. 사진 처리는 기존 로컬 처리 방식을 유지합니다.
- 메인 JS의 Vite 청크 크기 경고는 남아 있습니다. 전 앱에 대한 성능·보안 감사를 완료한 것은 아닙니다.
- GitHub Actions에서 Android APK와 서명되지 않은 iOS IPA를 생성합니다. 스토어 심사·배포 및 iOS 설치용 서명은 별도 절차입니다.

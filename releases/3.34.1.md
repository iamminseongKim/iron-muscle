# v3.34.1

## 최신 업데이트 핵심 요약
- 운동 시작 화면의 부위 선택 카드에 체크 표시와 선택 테두리를 추가하고, 밝은 테마와 어두운 테마의 표면 구분을 다듬었습니다.
- 시작 버튼, 부위 선택, 헤더, 하단 메뉴에 짧고 일관된 눌림 피드백을 적용했습니다. 헤더 터치 영역을 확대하고 반복 점멸을 줄였습니다.
- 키보드로 하단 메뉴를 이동하거나 모션 감소를 설정한 경우 불필요한 이동 효과를 생략합니다.
- 큰 휴식 타이머가 열린 동안 배경 스크롤을 잠그고 최소화·닫기 시 원래 위치를 복원합니다. 아래로 스와이프할 때 브라우저 스크롤이 함께 동작하는 문제를 수정하고 취소된 터치와 다중 터치를 처리합니다.
- 테마·강조색 전환 시 색상 전환이 뒤늦게 번지는 현상을 줄이고 타이머 숫자에 고정 폭 숫자 설정을 적용했습니다. 고대비 모드에서도 선택 부위의 테두리를 유지합니다.
- 기존 UI 문구, 8개 언어 팩, 운동 ID와 사용자 기록은 유지됩니다.

## 검증 및 한계
- `npm test`: 19개 테스트 묶음 통과. `npm run build` 통과(기존 큰 청크 크기 경고 포함).
- Chrome 화면 회귀 검증: 320·390·768px, 운동 전·진행 중·종목 선택·다크 모드·전체 탭과 8개 언어 통과.
- `scripts/test-rest-scroll-ui.mjs`: 실제 터치 이벤트로 배경 잠금, 스와이프 최소화 및 정확한 스크롤 위치 복원, 작은 타이머 드래그, 짧은 화면의 내부 스크롤과 닫기 정리 확인.
- 밝은/어두운 테마 화면을 시각적으로 확인하고 모션 감소 설정에서 버튼 전환이 생략되는 것을 확인했습니다.
- 실제 Android·iOS 기기에서의 터치 감각, 앱 설치와 스토어 배포는 로컬 검증에 포함되지 않습니다.

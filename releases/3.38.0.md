# v3.38.0

## 최신 업데이트 핵심 요약
- 스미스·케이블을 여러 운동이 함께 사용하는 공용 장비로 등록할 수 있습니다. 관련 종목마다 반복 체크하지 않아도 브랜드·부하 방식·kg/lbs·장비 메모가 적용됩니다.
- 전용 머신은 종목별로 등록하며, 기존 스미스·케이블 개별 설정은 보존하고 공용 설정보다 우선 적용합니다. 개별 등록 해제 시 공용 설정을 사용합니다.
- 공용 장비별 최대 3대의 설정과 헬스장별 분리를 지원합니다. 운동 선택 시 공용 장비를 사용할 수 있는 종목도 내 헬스장 목록과 우선 노출에 반영됩니다.
- 운동 카드에서 스미스·케이블을 등록해도 공용 장비로 등록됩니다. 새 종목·사용자 종목도 장비 분류에 따라 공용 설정을 사용합니다.
- 기존 운동 ID·기록·개별 머신 설정을 변경하지 않으며 브랜드를 자동 지정하지 않습니다. 안내와 설정 문구를 8개 언어 팩에 반영했습니다.

## 검증 및 한계
- `npm test`: 공용 설정 적용, 개별 설정 우선순위, 등록 해제, 헬스장 분리, 저장·재로드, 백업·복원 및 손상된 공용 설정 처리를 포함한 26개 테스트 묶음 통과.
- `npm run build`: TypeScript 검사, 웹 빌드, 모델 검증 및 오프라인 셸 생성 통과. 기존 큰 청크 경고는 남아 있습니다.
- Chrome에서 320/390px 화면, 장비 등록·단위 변경·다시 열기, 기존 설정 보존, 운동 선택 시 공용 장비 ID와 lbs 전달을 검증했습니다.
- Android 실기기에서의 설치·실행은 직접 검증하지 않았습니다. 케이블 높이·부속품·비율에 따라 모든 운동이 가능한 것은 아니므로 실제 장비에 맞춰 종목을 선택해야 합니다.

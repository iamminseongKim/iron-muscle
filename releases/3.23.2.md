# v3.23.2

## 최신 업데이트 핵심 요약
- 브라우저 탭 및 웹앱 파비콘을 고해상도 벡터 브랜드 마크(brand-mark.svg, icon-192.png, favicon.ico)로 전면 연결하여 기본 지구본 아이콘 문제를 해결했습니다.
- 'Apple 스타일' 등의 특정 브랜드 종속 문구를 모두 제거하고, 쇠질과 성장의 가치를 담은 감성 슬로건("아이언 머슬 | 쇠와 땀, 묵묵한 성장의 여정")으로 타이틀을 개편했습니다.
- 한국어, 영어, 일본어, 중국어(간체/번체), 스페인어, 프랑스어, 독일어 등 8개 국어 언어팩에 공식 앱 타이틀을 등록하고, 언어 설정 변경 시 브라우저 탭 제목(document.title)이 실시간 동기화되도록 개선했습니다.
- Node 16 환경 호환성을 위해 백업 및 커스텀 운동 테스트 스크립트의 structuredClone 폴리필을 보강했습니다.

## 검증 및 한계
- npm test (15개 전체 테스트 스위트 통과), npm run build (TypeScript 컴파일, Vite 빌드, 3D 모델 최적화 통과), npm run cap:sync (Android/iOS 에셋 및 플러그인 동기화 통과)를 모두 완료했습니다.
- 브라우저 SVG 파비콘 로드 및 언어 변경 시 document.title 갱신을 확인했습니다.
- 실제 앱스토어/플레이스토어 심사 및 배포는 별도 절차로 진행됩니다.

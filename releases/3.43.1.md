## 최신 업데이트 핵심 요약

루틴 구성 확인 모달에 앱 디자인과 일치하는 전용 종목 검색 선택창(SearchableExerciseSelect)을 도입하여 모바일 화면을 가리던 브라우저 기본 선택창을 개선했습니다.

- 루틴 구성 확인 모달에서 종목 변경 시 화면 전체를 덮던 OS 기본 `<select>` 드롭다운을 제거하고, 다크/라이트 모드 테마에 맞춘 세련된 인앱 검색 선택 팝오버를 적용했습니다.
- 운동 종목 검색창을 선택 팝오버 상단에 배치하고, 검색어 입력 시 종목명·영문명·별칭·초성(예: 'ㄹㄱ' -> 레그컬)까지 즉각 검색되도록 지원했습니다.
- '전체', '가슴', '등', '하체', '어깨', '팔', '복근', '전신' 부위별 필터 칩을 제공하여 원하는 운동을 빠르게 찾을 수 있도록 했습니다.
- 선택된 종목의 주동근 배지와 운동 카테고리를 직관적으로 표기하고, 새 커스텀 운동 등록 시에도 즉시 카탈로그에 동기화되어 바로 선택할 수 있도록 연동을 강화했습니다.
- 8개 언어 팩(ko, en, ja, zh-CN, zh-TW, es, fr, de)에 신규 검색 선택창 UI 텍스트 번역을 모두 반영했습니다.

## 검증

- `npm test`: 전체 29개 테스트 스위트 100% 통과 (i18n 언어 팩 동기화, 카탈로그 무결성, 적응형 세션, AI 루틴 가져오기).
- `npm run build`: TypeScript 컴파일, Vite 프로덕션 번들링, 3D 해부학 모델 최적화 및 오프라인 셸 빌드 통과.
- `node scripts/test-ai-routine-import-ui.mjs`: 모바일 뷰포트에서 AI 루틴 파싱, 모달 미리보기, 8개 언어 UI 에뮬레이션 통과.
- `node scripts/test-ai-custom-import-ui.mjs`: 새 커스텀 운동 등록 후 종목 자동 매칭, 영문 충돌 검사, 세션 저장 및 시작 흐름 전체 자동화 브라우저 테스트 통과.

## 검증 한계와 지원 범위

- 네이티브 모바일 앱(Android/iOS) 환경의 실제 터치 동작 및 키보드 오버레이는 Chromium 모바일 에뮬레이션 뷰포트(390x844)로 검증했습니다.
- 종목 검색 팝오버는 접근성 및 자동화 도구 호환성을 위해 숨겨진 동기화 셀렉트를 포함하고 있습니다.

### 🌟 최신 업데이트 핵심 요약

- **Android 인증 이미지 저장 경로 개선**: Android 10 이상에서 Pictures/IronMuscle 갤러리 폴더에 PNG를 저장합니다. 파일 쓰기와 닫기를 완료한 후 저장 내용을 원본 바이트와 비교하고, 검증에 성공한 이미지에만 저장 완료를 표시합니다. 실패 시 생성한 파일을 정리합니다.
- **운동 인증 카드 앞·뒤 해부도 추가**: 카드 오른쪽 아래에 기존 앱의 전면·후면 해부도를 표시합니다. 완료 세트가 있는 종목의 주동근은 분홍색, 협응근은 주황색으로 표시하며, 부위 정보가 없는 종목은 추측하지 않습니다.
- **버전별 릴리즈 설명**: 반복되던 과거 기능 목록을 제거하고 해당 버전의 변경 내역을 사용하도록 배포 워크플로를 변경했습니다.

이번 버전은 저장 오류 수정과 새로운 해부도 기능을 포함한 하위 호환 기능 추가이므로 3.13.0 → 3.14.0으로 올렸습니다.

갤럭시 실기기의 저장·첨부 재확인은 필요합니다. 자동 빌드 성공은 실기기 검증을 대신하지 않습니다.

## 최신 업데이트 핵심 요약

AI 처방과 실제 수행을 분리한 적응형 훈련 기록을 추가했습니다. 목표 RPE를 실제 RPE로 복사하지 않으며 미입력 실제 RPE는 null로 유지합니다. 다음 세트 중량 제안은 사용자가 적용을 눌러야 반영합니다.

- 계획 중량·반복수·RPE·휴식·템포·세트 유형·메모를 별도로 보존합니다. 기존 JSON 필드와 신규 계획 필드를 모두 가져올 수 있습니다.
- 워밍업, 활성화, 본세트, 탑세트, 백오프, 드롭세트, 미지정을 구분합니다. 워밍업과 활성화는 본세트 및 새 PR 분석에서 제외합니다. 드롭 구간은 중복 없이 합산합니다.
- 직접 입력한 운동은 기본 중량·반복수를 처방으로 만들지 않습니다. 목표를 설정한 경우에만 목표값을 표시하고 일반 기록에는 체감 강도와 세트 메모 문구를 사용합니다. 외부 AI 도움말은 선택해서 펼칩니다.
- 카드를 길게 눌러 위아래로 옮겨 정렬할 수 있습니다. 묶음 종목은 함께 이동하고 입력칸 조작·스크롤과 구분합니다. 기존 화살표 정렬도 유지합니다.
- 세트 완료 피드백, 부드럽게 움직이고 손을 뗄 때 저장하는 0.5 단위 RPE 슬라이더와 짧은 여유 반복수 설명, 독립적인 실패 유형, 자극·통증·메모, 이전 세트 값 복사, 완료 취소와 수정 이력을 추가했습니다. 상세 설문과 피드백 모달은 설정에서 조절합니다.
- 세트 진행 버튼 하나에 시작·세트 완료·완료 취소를 글자로 표시합니다. 앞 세트가 끝나기 전에는 다음 세트를 시작할 수 없고, 동시에 진행 가능한 세트는 하나입니다. 잘못 시작한 세트는 상세 옵션에서 시작을 취소합니다. 슈퍼세트의 각 종목을 개별 완료합니다. 실제 휴식은 이전 완료부터 명시적 세트 시작까지 측정하며 운동 일시정지를 제외합니다. 전환 시간과 라운드 휴식을 구분합니다. 타이머를 닫는 동작은 실제 휴식을 생성하지 않습니다.
- 활성 세션의 시작·완료 시각, 피드백, 일시정지와 휴식 타이머를 복구합니다. 알림음과 진동을 따로 설정하며 지원 환경에서 화면 유지 옵션을 제공합니다.
- 선택형 운동 전 컨디션·수면·피로·통증·식사·메모, 프로그램 단계·주차·목적과 종목 종료 피드백을 추가했습니다.
- 실제 본세트와 장비 조건에 근거한 이전 기록 비교와 규칙 기반 중량 제안을 추가했습니다. 통증 위치 또는 강도가 기록되면 제안을 중단합니다. 실제 RPE가 없으면 RPE 기반 제안을 하지 않습니다.
- Markdown v3.0은 8개 언어로 계획과 실제, 본세트·미지정 집계, 드롭 구간, 컨디션, 이전 기록 비교와 데이터 품질 한계를 출력합니다. 고정 4개 질문을 프로그램 단계와 실제 특이사항을 우선하는 코칭 요청으로 교체했습니다.
- 기존 저장 키, 운동 ID와 원본 값을 보존합니다. 과거 RPE·휴식·템포의 출처를 확정할 수 없으면 출처 불명으로 표시합니다. 기존 데이터 전체를 새 계획값으로 임의 변환하지 않습니다.

## 검증

- `npm test`의 기존 테스트와 적응형 모델·분석 테스트를 실행합니다.
- `npm run build`로 TypeScript 및 배포용 웹 빌드를 확인합니다.
- `node scripts/test-adaptive-ui.mjs`로 모바일 브라우저에서 목표·실제 RPE 분리, 미입력, 승인 전후 중량, 슈퍼세트 독립 완료, 시작 시점 휴식, 재실행 복구, 완료 취소·재완료와 반응형 레이아웃을 검증합니다. `node scripts/test-card-drag-ui.mjs`로 마우스·터치 길게 누르기 정렬, 묶음 보존, 입력칸 제외와 취소 동작을 검증합니다.
- 기존 기록 보존, JSON·루틴·백업 호환성, kg/lbs 변환, 덤벨 한 손 기준과 스미스 봉 무게 미추가를 테스트합니다.

## 검증 한계와 지원 범위

- 실제 Android 기기의 프로세스 강제 종료·알림 권한·백그라운드 알림음·진동·화면 유지 동작은 이번 로컬 검증에서 확인하지 않았습니다. 브라우저 재실행 복구와 네이티브 빌드 결과를 기기 실측으로 간주하지 않습니다.
- 새 Markdown v3.0은 코칭용 내보내기입니다. v3.0 Markdown 재가져오기는 지원하지 않습니다. 기존 Markdown 가져오기는 유지하며, 손실 없는 이전·복원은 JSON 백업을 사용합니다.
- 화면 유지는 Web Wake Lock 지원 환경에서 동작합니다. 지원하지 않거나 운영체제가 거부하면 화면 유지가 보장되지 않습니다.
- 시작하지 않은 세트의 실제 휴식과 워밍업 시간은 추정하지 않습니다. 사용자가 직접 입력한 과거 휴식은 측정값과 별도로 출처를 저장합니다.
- 장비 ID가 없는 머신은 새 기록 비교를 제한합니다. 과거 그래프의 미분류 기록은 보존하며 본세트로 확정하지 않습니다.
- 중량 제안은 기록된 RPE 편차와 사용자가 설정한 증가 단위를 사용합니다. 외부 AI 호출이나 자동 운동 처방 변경은 없습니다. 1RM은 추정값입니다.

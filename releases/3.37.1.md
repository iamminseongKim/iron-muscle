# v3.37.1

## 최신 업데이트 핵심 요약
- 앱 업데이트의 APK 다운로드 버튼이 GitHub 다운로드 링크를 외부 브라우저로 엽니다. 앱 전용 폴더에 직접 다운로드하던 방식을 대체했습니다.
- 브라우저에서 다운로드한 APK를 열어 설치하도록 버튼과 안내 문구를 8개 언어로 변경했습니다.
- 기존 앱과 운동 기록을 유지하는 업데이트 설치 방식을 유지합니다.

## 검증 및 한계
- `npm test`: 25개 테스트 묶음 통과. `npm run build`: TypeScript 검사, 웹 빌드, 모델 검증 및 오프라인 셸 생성 통과. 기존 큰 청크 경고는 남아 있습니다.
- Android APK 컴파일과 배포는 GitHub Actions에서 확인합니다. Android 실기기의 브라우저 선택·다운로드·설치 동작은 직접 검증하지 않았습니다.
- 이 수정이 포함된 버전의 최초 설치는 GitHub 릴리즈에서 APK를 직접 내려받아 기존 앱 위에 설치해야 합니다.

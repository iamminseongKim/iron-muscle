# Iron Muscle Tracker 3.28.3

## 최신 업데이트 핵심 요약
- **GitHub Actions CI/CD 빌드 성능 최적화**:
  - `build-web` 공통 Job을 신설하여 웹 번들링(`npm run build`)과 회귀 테스트(`npm test`)를 단 1회만 실행하고 산출물(`dist/`)을 Android/iOS 러너로 전달하도록 파이프라인을 개편했습니다.
  - Android APK 빌드에 `gradle/actions/setup-gradle@v3` 캐시를 적용하여 Gradle 빌드 시간을 대폭 단축했습니다.
  - 비싼 macOS 러너의 중복 웹 빌드/테스트 스텝을 완전히 제거하여 iOS 패키징 속도를 향상했습니다.
  - 동일 브랜치/태그 중복 실행 시 이전 큐를 안전하게 취소하는 동시성 제어(`concurrency`)를 추가했습니다.
- **단위/회귀 테스트 병렬 실행 도입**:
  - 17개 테스트 스위트를 멀티코어로 병렬 실행하는 `scripts/run-all-tests.mjs`를 적용하여 테스트 소요 시간을 20초에서 7초로 대폭 단축했습니다.

## 검증 범위 및 한계
- 로컬 `npm test` 병렬 실행 정상 통과 및 `npm run build` 검증 완료.
- GitHub Actions 클라우드 환경에서 아티팩트 다운로드 및 플랫폼별(Android, iOS) 빌드 파이프라인 무결성 검증.

# v3.28.7

## 최신 업데이트 핵심 요약
- **운동 기록 날짜 UTC 왜곡 버그 해결**:
  - 운동 세션 시작 시 `new Date().toISOString().split('T')[0]`(UTC 기준)을 사용하여 한국 시간(KST) 오전 0시~9시 운동이 전날 날짜로 기록되던 문제를 `getTodayString()`(로컬 시간 기준)으로 교정했습니다.
- **과거 왜곡 세션 자동 복구(마이그레이션) 탑재**:
  - 앱 실행 및 세션 로드 시(`loadSavedSessions`, `loadActiveSession`), `startTime`은 정상(로컬 16일 아침)이나 `date`가 UTC 절삭으로 인해 전날(15일)로 저장된 기존 세션을 자동 감지하여 올바른 로컬 날짜로 자동 보정·영구 저장합니다.
  - 사용자가 과거 날짜로 의도하여 수기 작성한 기록은 영향을 받지 않도록 안전한 불일치 패턴만 선별 보정합니다.
- **백업 및 AI 내보내기 날짜 정합성 확보**:
  - 백업 파일명 및 AI 마크다운 일지 생성 시 사용자의 로컬 날짜를 일관되게 반영하도록 정비했습니다.
  - 캘린더 유틸리티(`src/utils/calendar.ts`)에 임의 일수 증감(`addDays`) 기능을 추가하고, 주간 분석 범위 계산 시 발생하던 잠재적 날짜 왜곡을 방지했습니다.

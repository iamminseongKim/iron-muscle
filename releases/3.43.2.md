## 최신 업데이트 핵심 요약

모바일 소프트웨어 키보드가 활성화되었을 때 루틴 구성 확인 모달 내 종목 선택 영역이 가려지거나 좁아지던 가독성 문제를 해결했습니다.

- 모바일 가상 키보드가 열리면 카드 내 인라인 드롭다운이 미리보기 모달 헤더와 하단 버튼 사이에 끼여 검색 결과가 1~2개만 표시되던 구조적 한계를 개선했습니다.
- 종목 선택 시 전용 키보드 대응 모달 레이어(`.exercise-picker.keyboard-aware-modal`, z-index 60)를 오버레이로 띄워, 키보드 상단의 전체 화면 영역을 온전히 검색과 종목 탐색 공간으로 활용하도록 개편했습니다.
- 키보드가 올라오면 부가 설명을 자동 숨김 처리하고 상단 검색창, 부위별 필터 칩, 그리고 넓은 스크롤 목록을 제공하여 쾌적하게 종목을 선택할 수 있도록 했습니다.
- 종목을 터치하면 즉시 선택이 적용되면서 키보드가 닫히고 루틴 구성 확인 모달로 복귀합니다.
- 기존 자동화 테스트 및 스크린 리더와의 완벽한 호환을 위해 숨겨진 동기화 셀렉트(`select[data-ai-exercise-select]`) 구조를 유지했습니다.

## 검증

- `npm test`: 29개 테스트 스위트 100% 통과 (i18n, AI 루틴 가져오기, 카탈로그 무결성 등).
- `npm run build`: TypeScript 컴파일, Vite 프로덕션 빌드, 오프라인 셸 패키징 완료.
- `node scripts/test-ai-routine-import-ui.mjs`: 브라우저 자동화 테스트 통과 (8개 언어 모달 미리보기, 타이머, 메타데이터 연동).
- `node scripts/test-ai-custom-import-ui.mjs`: 커스텀 운동 등록 및 세션 시작 테스트 통과.
- 가상 키보드 높이(420px 축소 뷰포트) 에뮬레이션 테스트를 통해 모바일 검색 시 100% 가독성 및 터치 영역 확보 확인.

# v3.27.2

## 최신 업데이트 핵심 요약
- 외부 Android SDK 설정 액션이 GitHub의 Ubuntu 러너에서 권한 오류로 중단되는 문제를 피하도록 워크플로를 수정했습니다.
- GitHub Ubuntu 러너에 기본 제공되는 Android SDK 경로와 `sdkmanager`를 직접 검증한 뒤 APK 빌드를 진행합니다.
- v3.27.0의 머신 브랜드 직접 입력, 모바일 하단 메뉴 배치, 스미스 장비 분류 변경을 그대로 포함합니다.

## 검증 및 한계
- 로컬 `npm test`와 `npm run build`를 통과한 뒤 태그를 푸시합니다.
- Android APK와 iOS IPA 생성 및 GitHub Release 게시 여부는 v3.27.2 GitHub Actions 실행이 완료될 때까지 확인합니다.

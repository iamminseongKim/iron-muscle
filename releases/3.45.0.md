# 3.45.0

## 최신 업데이트 핵심 요약

- 완료 설문의 실제 RPE와 피드백을 워밍업에서도 기본으로 펼쳐 표시합니다. 저장 버튼은 설문 안에서 스크롤해도 접근할 수 있도록 하단에 유지합니다.
- 템포를 직접 숫자로 입력하는 대신 프리셋과 이완·정지·수축별 ±0.5초 버튼으로 조절합니다. 0~30초 범위와 목표 템포로 복원을 지원합니다. 원래 목표와 실제 입력 출처를 보존합니다.
- 목표 RPE는 황갈색, 목표 템포는 청록색으로 설문과 운동 세트에 표시합니다. 텍스트 라벨도 함께 제공해 색상만으로 구분하지 않습니다.
- 보조 반복수와 통증 부위·강도의 개별 입력을 없애고 세트 메모에 자유롭게 적도록 바꿨습니다. 종목 피드백의 통증도 종목 메모에 남깁니다. 기존에 저장한 구조화된 기록은 읽기 전용으로 표시하고 백업·내보내기에서 보존합니다.
- 새 문구는 8개 언어에 반영했습니다. 항상 펼쳐지는 설문에서 더 이상 필요 없는 상세 표시 설정은 화면에서 제거했습니다. DB 구조와 JSON 형식은 변경하지 않았습니다.

## 검증

- 이전 v3.44.0 설문 컴포넌트로 워밍업 RPE 접힘과 숫자 템포 입력을 실제 Chrome에서 재현했습니다.
- `test-feedback-ux-ui`에서 기본 펼침, 메모 입력과 기존 기록 보존, 목표 색상 구분, 320·390·768px 및 밝은·어두운 화면을 확인했습니다.
- `npm test` 전체 31개 테스트 묶음과 `npm run build`의 TypeScript·웹 빌드·모델 검증·오프라인 셸 생성이 통과했습니다. 기존 큰 청크 경고는 남아 있습니다. `test-prescription-survey-ui`의 수행 템포 수정·복원·완료 기록 재수정과 `test-adaptive-ui`의 기존 RPE·세트 진행·휴식·모바일 회귀도 통과했습니다.

## 한계

- 실제 Android 기기에서는 확인하지 않았습니다.
- 메모에 적은 통증과 도움받은 반복은 자유 텍스트로 내보내며 숫자 지표로 추정하지 않습니다.

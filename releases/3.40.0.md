# v3.40.0

## 최신 업데이트 핵심 요약
- AI 루틴 가져오기에서 미등록 종목을 새 사용자 운동으로 등록하고 원래 루틴에 연결할 수 있습니다.
- AI가 제안한 운동 부위와 주동근·보조근을 등록 전에 확인하고 수정합니다. 제안이 없으면 부위와 주동근을 직접 선택해야 합니다.
- 여러 주동근을 선택할 수 있습니다. 한글명과 영문명이 기존 종목과 충돌하면 새 등록을 막아 이름 매칭을 유지합니다.
- 기존 종목의 근육 정보는 유지합니다. AI 제안을 자동으로 저장하거나 기존 운동 ID와 기록을 덮어쓰지 않습니다.
- 외부 AI용 질문과 JSON·Markdown 입력 형식에 근육 제안 형식을 추가합니다. 새로운 안내 문구는 8개 언어를 지원합니다.

## 검증 및 한계
- `npm test`: 27개 테스트 묶음 통과. JSON·Markdown 근육 제안, 지원 ID 검증, 다중 주동근, 제안 누락과 기존 종목 보존을 확인했습니다.
- `npm run build`: TypeScript, 웹 빌드, 모델 검증과 오프라인 셸 생성 통과. 기존 큰 청크 경고가 남아 있습니다.
- 신규 등록 UI 자동 검증으로 8개 언어, 취소, 미선택 등록 차단, 다중 주동근, 손상된 저장소·용량 부족 시 원본 보존, 한글명·영문명 중복 차단, 재불러오기와 실제 근육 집계를 확인했습니다.
- 기존 AI 루틴 UI 회귀 검증도 통과했습니다. 등록 화면이 배경 버튼보다 앞에 표시되는지 실제 화면 위치로 검사했습니다.
- 실제 브라우저에서 AI의 광배근·승모근 제안을 서로 바꾸고 핀로드를 플레이트로드로 수정했습니다. 등록 후 세트 유지와 변경된 주동근·보조근의 해부도 표시를 확인했습니다.
- AI가 제안한 해부학 정보의 정확성을 앱이 판정하지 않습니다. 사용자가 확인한 근육 분류를 저장합니다.
- Android 실기기 검증은 수행하지 않았습니다. APK 빌드와 배포 상태는 GitHub Actions 결과로 확인합니다.

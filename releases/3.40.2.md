# v3.40.2

## 최신 업데이트 핵심 요약
- 코드베이스 전수 조사를 통해 호출되지 않는 미사용 레거시 뷰어(`AnatomyDualViewer.tsx`)와 절차적 지오메트리 파일(`MuscleGeometryFactory.ts`) 213줄을 정리했습니다.
- 실제 통계 및 UI에서 참조하지 않는 긴장 지속시간 계산 유틸 함수(`calculateSetTUT`, `calculateTUTLoad`)를 제거했습니다.
- 기존 운동 ID, 세트 기록, 3D 뷰어, 공유 카드 및 번역 데이터는 모두 유지됩니다. 신규 문구 추가는 없습니다.

## 검증 및 한계
- `npm test`: 27개 테스트 묶음 통과. 데이터 정합성, 백업 복원, 운동 세션 완료, 3D 해부도 및 공유 카드 생성 회귀 검증을 확인했습니다.
- `npm run build`: TypeScript 컴파일, 웹 빌드, 3D 모델 검증과 오프라인 셸 생성 통과.
- 프로젝트 전체 심볼 검색을 통해 삭제 대상 파일 및 함수를 참조하는 곳이 없음을 확인했습니다.
- 개별 세트 템포 모달과 코멘트 모달, 타이머 잠금 분리 등 2단계 사용자 경험 개선은 기존 데이터 호환성 검토 후 순차 진행할 수 있도록 이번 릴리즈에서는 미사용 코드 삭제에 집중했습니다.
- Android 실기기 검증은 수행하지 않았습니다. APK 빌드와 배포 상태는 GitHub Actions 결과로 확인합니다.

# v3.41.0

## 최신 업데이트 핵심 요약
- 운동 중 기구가 다른 사용자에게 점유되어 있거나 순서를 변경해야 할 때, 각 운동 카드에서 즉시 상/하(`▲`/`▼`)로 이동할 수 있는 직접 정렬 버튼을 추가했습니다.
- 전체 루틴을 한눈에 보며 순서를 바꿀 수 있는 '종목 순서 변경' 전용 모달을 추가했습니다. 종목 번호와 세트 현황, 슈퍼세트 묶음 상태를 확인하며 원터치로 순서를 재배치할 수 있습니다.
- 기구가 꽉 차서 다른 운동으로 대체해야 할 때, 운동 카드에서 '종목 교체' 버튼(`⇄`)을 눌러 동일 부위의 대체 운동으로 현재 자리에서 즉시 교체하는 기능을 추가했습니다. 기존에 계획된 세트와 루틴 위치가 안전하게 보존됩니다.
- 신규 UI 문구(종목 순서 변경, 운동 종목 교체, 기구 점유 시 대체 안내 등)를 8개 언어(한국어·영어·일본어·중국어 간체/번체·스페인어·프랑스어·독일어) 언어 팩에 모두 등록했습니다.

## 검증 및 한계
- `npm test`: 27개 테스트 묶음 통과. 인플레이스 종목 대체 로직(`replaceWorkoutExercise`), 블록 단위 슈퍼세트 순서 이동, 8개 언어 UI 키 누락 검증을 모두 완료했습니다.
- `npm run build`: TypeScript 컴파일, Vite 빌드, 3D 모델 검증, 오프라인 셸 생성 통과.
- 슈퍼세트/컴파운드세트로 묶인 종목은 함께 이동하며 그룹 불변성을 유지합니다.
- 기존 완료한 세트가 있는 상태에서 종목을 교체하면 완료 플래그가 초기화되므로, 이미 수행을 마친 종목보다는 기구 점유로 시작하지 못한 종목의 대체에 적합합니다.
- Android 실기기 검증은 수행하지 않았습니다. APK 빌드와 배포 상태는 GitHub Actions 결과로 확인합니다.

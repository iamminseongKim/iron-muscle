# v3.28.0

## 최신 업데이트 핵심 요약
- **커스텀 운동 직접 등록 시 보조근(협응근) 다중 선택 지원**:
  - 카테고리별 추천 보조근 칩을 기본 제공하고, '모든 근육 부위 보기'를 통해 17개 전체 해부학 근육 중 원하는 협응근을 자유롭게 복수 선택할 수 있습니다.
  - 주동근 변경 시 보조근 목록에서 자동 제외되어 데이터 무결성을 유지합니다.
- **3D 해부학 모델링 복직근(식스팩) 노출 및 클릭 판정 개선**:
  - 외복사근(obliques) 메쉬가 복직근 앞면을 덮는 전면 건막 판을 절제하여 식스팩 윤곽이 선명하게 드러납니다.
  - 복부 전면 클릭 시 복직근(abs)이 최우선으로 정확하게 선택되도록 Raycasting 판정 로직을 강화했습니다.
- **운동 탐색(ExerciseExplorer) 3D 하이라이트 동기화 개선**:
  - 3D 모델에서 근육 선택 시 이전 선택 운동의 주동근·협응근(빨강/주황)이 즉시 초기화되고 선택한 근육만 파란색으로 집중 표시됩니다.
  - 목록에서 운동 종목을 선택하면 파란색 모드가 해제되고 해당 운동의 주동근·협응근이 3D에 즉시 반영됩니다.
- **3D 뷰어 확대 시 상하 이동(Pan) 지원**:
  - OrbitControls의 Pan 이동을 활성화하고 뷰어 컨트롤 바에 상하 시점 이동 버튼(▲/▼)을 추가하여, 확대 상태에서도 상체(가슴/어깨/목)와 하체(허벅지/종아리) 근육을 쉽게 확인하고 선택할 수 있습니다.
- **8개 국어 언어 팩(i18n) 완비**:
  - 한국어, 영어, 일본어, 중국어(간체/번체), 스페인어, 프랑스어, 독일어 번역을 지원합니다.

## 검증 및 한계

- 커스텀 운동 보조근 저장/복원 회귀 테스트(`test-custom-exercises.mjs`) 및 다국어 팩 일관성(`test-i18n.mjs`)을 검증했습니다.

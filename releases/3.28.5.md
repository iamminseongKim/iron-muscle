# Iron Muscle Tracker 3.28.5

## 최신 업데이트 핵심 요약
- 선호하던 반투명 플로팅 하단 메뉴의 유리 효과와 화면 위에 떠 있는 배치를 복원했습니다.
- 운동 시작 버튼을 목표 부위 카드 바로 아래의 엄지가 닿기 편한 중간·하단 영역으로 옮겨 하단 메뉴와 명확히 분리했습니다.
- 높이가 낮은 소형 폰에서는 상단 안내와 목표 부위 카드를 압축하고, 가로 화면에서는 버튼이 메뉴 뒤에 일부만 보이지 않도록 스크롤 영역 아래에 배치합니다.
- 펼친 폴드폰과 분할 화면에서는 시작 버튼이 왼쪽 목표 부위 패널 아래에 유지되며, 하단 플로팅 메뉴와 겹치지 않습니다.
- 기존 머신 브랜드 직접 입력, 스미스 장비 분류, Android 빌드 복구 변경을 모두 유지합니다.

## 검증 범위 및 한계
- `npm test`와 `npm run build`를 실행해 기능 회귀와 프로덕션 번들을 검증합니다.
- 320×568, 360×640, 390×844, 430×932, 673×841, 768×1024, 884×1104, 960×1080, 844×390 화면을 하단 안전 영역 0px/34px 조건에서 확인합니다.
- 브라우저 자동 검증으로 플로팅 메뉴의 `fixed` 배치와 블러 효과, 최초 화면 및 스크롤 후 시작 버튼과 메뉴 사이 8px 이상 간격을 확인합니다.
- 실제 폴드 기기의 물리적 힌지 영역과 제조사별 웹뷰 렌더링은 실기기 확인이 필요합니다.

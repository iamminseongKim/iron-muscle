# v4.0.0 — 마이 탭과 건강 앱 연결 MVP

## 최신 업데이트
- 하단 다섯 번째 **마이** 탭: 체중 관리, 건강 앱 연결, 언어·테마·표시 단위, 백업·복원과 개인정보 안내를 모았습니다.
- Apple HealthKit / Android Health Connect에서 최근 체중을 가져오고, 연결 후 완료하는 근력 운동을 보냅니다. 체중 가져오기·운동 보내기는 각각 사용자가 켜야 합니다.
- 체중 수동 입력과 kg/lbs 표시를 지원하며 측정 날짜와 출처를 표시합니다. 새 운동에 운동 당시 체중을 저장하고 기존 기록을 보존합니다.
- 운동 로컬 저장을 먼저 확인한 뒤 전송합니다. 실패한 전송은 마이에서 재시도할 수 있고 세션 ID로 중복 전송을 방지합니다.
- 8개 언어의 UI·개인정보 안내 및 iOS 건강 권한 설명을 추가했습니다.

## 호환성 변경
- 공식 Health Connect SDK 요구사항에 따라 Android 최소 지원 버전을 5.1에서 **8.0(API 26)**으로 올렸습니다. 이 변경 때문에 major 버전 4.0.0을 사용합니다.
- Health Connect 연결은 Android 9 이상에서 지원합니다. 삼성 헬스에서도 별도 공유 권한이 필요합니다. iOS 최소 13을 유지합니다.
- 운동 ID, 머신 브랜드, 기존 사용자 기록 및 백업 형식은 유지합니다.

## 검증과 범위
- `npm test`, `npm run build`: 통과. 건강 연결 테스트는 opt-in, 빈/거부된 읽기, 저장 오류, 수동 수정과 자동 조회의 충돌, 실패 재시도, 동시 중복 방지, 체중 스냅샷의 백업 보존을 검증합니다.
- 브라우저: 390px 마이 탭, 체중 입력과 kg/lbs 변환, 언어 전환 확인. 웹에서는 건강 연결을 비활성화합니다.
- Android/iOS 네이티브 컴파일과 산출물은 이 태그의 GitHub Actions 결과로 확인합니다. 로컬 PC에는 Android SDK·전체 Xcode가 없어 로컬 네이티브 빌드는 수행하지 않았습니다.
- 실기기 권한 창, 실제 체중 조회·전송·권한 철회·삼성 헬스 반영은 미검증입니다. iOS IPA는 기존 파이프라인의 **unsigned** 산출물이며 서명·프로비저닝과 HealthKit capability가 필요합니다. App Store/TestFlight 배포를 의미하지 않습니다.
- 보내는 데이터는 근력 운동 유형과 시작/종료 구간입니다. 일시정지를 포함한 구간이므로 앱의 활성 운동 시간과 다를 수 있습니다. 칼로리·피트니스 링 반영은 보장하지 않습니다. 워치에서 따로 기록한 운동과 중복될 수 있습니다.
- 기존 볼륨·1RM 계산은 바꾸지 않습니다. 맨몸/어시스트 부하 계산, 실시간 심박수·수면·HRV·체성분 분석은 후속 범위입니다.
- 현재 체중·연결 설정·전송 대기열은 기기에만 저장하며 운동 백업에서 제외합니다. 세션에 저장된 운동 당시 체중은 기존 백업에 포함됩니다.

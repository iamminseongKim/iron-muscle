## 최신 업데이트 핵심 요약

앱 규모 확장에 따른 번들 크기 최적화(90% 메인 번들 경량화), 전역/하위 뷰 에러 바운더리를 통한 강제 종료(화이트스크린) 방어, 그리고 모바일 가상 키보드 UI 환경을 전면 개선했습니다.

1. **번들 분할 및 앱 규모 확장 최적화 (Code-splitting & Chunking)**:
   - 메인 엔트리 청크 크기를 기존 3,325 kB에서 **341 kB**로 약 90% 대폭 절감했습니다.
   - 대용량 운동 데이터 카탈로그(`data-exercises`, 1,642 kB)와 다국어 팩(`i18n-locales`, 1,130 kB), 벤더 라이브러리(`vendor-react`, `vendor-icons`), 마이페이지 컴포넌트(`MyPage`)를 분리하여 브라우저와 오프라인 서비스 워커가 독립적으로 캐싱하도록 최적화했습니다.
   - 앱 첫 실행 시 메인 화면(운동 기록창) 로딩 속도가 획기적으로 향상되었습니다.

2. **앱 강제 종료(크래시) 및 화이트스크린 방어 (Crash Hardening)**:
   - 전역 루트 및 개별 탭 뷰에 `ErrorBoundary`를 배치하여 렌더링 에러 발생 시 앱이 완전히 꺼지거나 흰 화면에 갇히는 현상을 원천 차단했습니다.
   - 일시적인 렌더링 에러 시 데이터 손실 없이 운동 기록을 즉시 JSON 파일로 구조할 수 있는 '데이터 백업 다운로드' 및 '진행 중 세션 초기화', '화면 다시 시도' 복구 옵션을 제공합니다.
   - `unhandledrejection` 및 전역 `error` 핸들러를 등록하여 비동기 프로미스 실패로 인한 웹뷰 크래시를 방지했습니다.
   - 로컬스토리지 손상(corrupted JSON) 및 용량 초과(`QuotaExceededError`) 시 비정상 종료 없이 안전하게 기본 상태로 폴백되도록 보강했습니다.

3. **모바일 가상 키보드 및 폼 UX 개선 (Mobile Keyboard Hardening)**:
   - 운동 일지 수정 모달(`EditSessionModal`), 헬스장 기구 관리 모달(`GymEquipmentModal`), 종목 묶기 모달(`ExerciseGroupModal`)에 `.keyboard-aware-modal` 및 뷰포트 맞춤 스크롤을 적용하여 모바일 키보드가 올라와도 저장/완료 버튼이 가려지지 않도록 개선했습니다.
   - 모바일(화면 폭 768px 이하)에서 입력 필드 포커스 시 iOS Safari가 화면 전체를 강제 확대(Auto-zoom)하여 레이아웃이 밀리는 문제를 방지하도록 폰트 크기(16px)를 최적화했습니다.
   - 빈 공간 및 모달 배경 터치 시 활성화된 가상 키보드가 자연스럽게 닫히도록 탭 감지(`handleTapOutside`)를 적용했습니다.
   - 검색창에서 키보드 엔터/완료 시 키보드를 자동으로 내리고 검색 결과를 넓게 확인할 수 있도록 지원했습니다.

4. **다국어 8개 언어 지원**:
   - 에러 바운더리 복구 및 안전 관련 UI 문구를 8개 언어(한국어, 영어, 일본어, 중국어 간체/번체, 스페인어, 프랑스어, 독일어) 언어 팩에 모두 반영했습니다.

## 검증

- `npm test`: 전체 30개 테스트 스위트 100% 통과 (신규 모바일 회복력 및 에러 바운더리 검증 스위트 포함).
- `npm run build`: TypeScript 컴파일, Vite 롤업 청크 최적화 빌드, 오프라인 셸(22개 에셋 캐시) 패키징 통과.
- `node scripts/test-ai-routine-import-ui.mjs`: 브라우저 자동화 테스트 통과 (8개 언어 모달 미리보기, 타이머, 메타데이터 연동).
- `node scripts/test-ai-custom-import-ui.mjs`: 커스텀 운동 등록 및 세션 시작 테스트 통과.
- 가상 키보드 높이(420px 뷰포트) 에뮬레이션 및 모바일 터치 블러 동작 검증 완료.

# 3.43.4

## 최신 업데이트 핵심 요약

- 운동 기록 화면에서 측정된 휴식을 직전에 완료한 세트 아래에 ‘세트 후 휴식’으로 표시합니다. 다음 세트 시작 전의 휴식이 다음 행의 운동 기록처럼 보이던 혼동을 수정했습니다.
- 종목 전환과 슈퍼세트에서도 실제 완료·시작 시각으로 이전 완료 세트에 연결합니다. 다음 세트 시작 취소 시 표시를 제거하고 재시작 후에도 복원합니다.
- 기존 세트 ID, 저장된 휴식과 분석 기준은 보존합니다. 측정 출처 또는 시작 시각이 없는 과거 기록과 수동 입력 기록은 임의로 다른 세트에 옮기지 않습니다.
- 새 UI 문구를 8개 언어에 반영했습니다.

## 검증

- `npm test`: 전체 30개 테스트 묶음 통과.
- `npm run build`: TypeScript, 웹 빌드, 모델 검증, 오프라인 셸 생성 통과. 기존 큰 청크 경고가 남아 있습니다.
- `node scripts/test-adaptive-training.mjs`: 세트 후 휴식 연결, 종목 전환, 시작 취소, 원본 보존 검증 통과.
- `node scripts/test-adaptive-ui.mjs`: 모바일 브라우저에서 이전 완료 세트 아래 표시, 재시작 복원, 시작 취소 시 표시 제거 및 320·390·768px 화면 검증 통과.

## 한계

- 실제 Android 기기에서의 확인은 수행하지 않았습니다. 저장된 완료·시작 시각이 없는 과거 휴식의 연결 관계는 추정하지 않습니다.

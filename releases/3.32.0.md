# v3.32.0

## 최신 업데이트 핵심 요약
- 운동 중 머신·스미스·케이블 종목 카드에서 해당 종목을 현재 활성 헬스장에 바로 등록할 수 있습니다.
- 이미 등록된 종목에는 등록 완료 상태를 표시하고 중복 등록을 막습니다. 빠른 등록은 브랜드를 자동 지정하지 않으며, 기존 운동 기록과 종목 ID를 유지합니다.
- 새 버튼과 상태 문구를 8개 언어 팩에 추가했습니다.

## 검증 및 한계
- `npm test`의 19개 테스트 묶음과 `npm run build` 통과.
- Chrome UI 검증에서 활성 헬스장 저장, 다른 헬스장과의 분리, 중복 등록 방지 상태, 브랜드 미지정을 확인했습니다.
- 실제 Android·iOS 앱 설치와 스토어 배포는 이 검증에 포함되지 않습니다.

# v3.27.1

## 최신 업데이트 핵심 요약
- GitHub Actions의 Android SDK 설정 액션을 Node.js 24 호환 버전으로 갱신해 Android APK 빌드가 시작 전에 중단되던 문제를 수정했습니다.
- Java 설정 액션도 Node.js 24 호환 버전으로 갱신했습니다.
- v3.27.0의 머신 브랜드 직접 입력, 모바일 하단 메뉴 배치, 스미스 장비 분류 변경을 그대로 포함합니다.

## 검증 및 한계
- 로컬 `npm test`와 `npm run build`를 통과한 뒤 태그를 푸시합니다.
- Android APK와 iOS IPA 생성 및 GitHub Release 게시 여부는 v3.27.1 GitHub Actions 실행 결과로 확인합니다.

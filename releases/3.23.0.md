# v3.23.0

## 최신 업데이트
- 운동 추가 화면은 최근 완료 기록·대표 종목·사용자 등록 종목부터 보여줍니다. 전체 목록은 버튼으로 전환하며, 검색은 전체 종목을 대상으로 합니다.
- 정확한 이름·8개 언어 번역·별칭 일치를 우선하고, 같은 관련도에서는 최근 기록과 대표 종목을 우선합니다. 검색 결과가 원본 배열 순서에 좌우되지 않습니다.
- 랫풀, 케이블 사레레, RDL, 리버스 펙덱, 트랩바 등 검색용 별칭을 보강했습니다. 부위와 장비를 조합한 검색도 지원합니다.
- 사용자가 고른 부위·장비 필터를 검색 중 유지하고 전체 부위로 전환할 수 있습니다. 자동 오늘 목표는 기존처럼 전체 부위 텍스트 검색을 허용합니다.
- 덤벨 루마니안 데드리프트, 스미스머신 루마니안 데드리프트, 시티드 케이블 플라이를 추가했습니다. 총 1,035종이며 신규 이름을 8개 언어에 등록했습니다.
- 데드버그 명칭과 코어 분류, EZ바 스컬 크러셔의 팔 분류를 수정했습니다. 검수한 중복 항목은 노출 순위를 조정하며 기존 ID와 기록은 보존합니다.
- 운동 탐색 화면에도 같은 검색 관련도·대표 종목 정렬을 적용했습니다.

## 검증 및 한계
- npm test 및 npm run build 통과. 모바일 검색 UI 회귀 검증 통과.
- 검색 회귀 검증: 대표 종목 ID, 별칭 상위 결과, 드문 종목 정확 검색, 다국어 새 종목 검색, 완료 기록만 반영, 순서 독립성, 기록 불변성.
- 모바일 UI 검증: 390×844 대표 목록, 390×440 어두운 화면, 자동 포커스 없음, 부위 필터 유지와 전체 검색 복구, 신규 종목 선택.
- 대표 종목은 편집 기준이며 전체 사용자 인기 통계가 아닙니다. 검색어나 기록을 외부로 전송하지 않습니다.
- 자료 대조는 1차 검수이며 전체 1,035종의 모든 설명을 재검수한 것은 아닙니다. 오타 유사 검색과 중복 기록 자동 통합은 포함하지 않습니다.
- 실제 iOS/Android 키보드와 설치 검증은 별도이며, 기존 대용량 번들 경고는 남아 있습니다.
- 추가 근거와 데이터 유지 지침: docs/exercise-discovery.md.

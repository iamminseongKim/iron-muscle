# v3.41.2

## 최신 업데이트 핵심 요약
- 운동 종목 검색(`rankExercises`, `matchesExerciseSearch`) 로직을 리팩토링하여 검색 속도를 약 18.9배 향상했습니다 (1회 검색당 14.26ms에서 0.75ms로 단축, 모바일 검색 반응성 대폭 개선).
- 각 운동 종목의 정규화된 검색 필드 및 초성 검색 인덱스를 `WeakMap`에 한 번만 계산하여 캐싱함으로써, 매 키 입력마다 반복되던 1,000여 개 운동의 유니코드 정규화(`NFKC`) 및 정규식 치환 오버헤드를 제거했습니다.
- 검색 순위 산정 시 빈번하게 재구성되던 카테고리/기구 컨텍스트와 대분류 키워드(`broadTerms`)를 사전 캐싱하여 불필요한 배열 생성 및 다국어 번역 함수 호출을 제거했습니다.
- `resolveExercise`에서 매 호출마다 발생하던 `localStorage.getItem` 및 `JSON.parse`를 변경 감지 기반의 O(1) 인메모리 맵 캐시(`getCustomExercise`)로 리팩토링하여 운동 기록 렌더링 및 세션 요약 시의 직렬화 오버헤드를 해소했습니다.
- 기존의 다국어 검색, 초성 검색, 커스텀 운동 해석 및 레거시 ID 매핑 등 모든 기능 계약과 동작은 100% 동일하게 유지됩니다.

## 검증 및 한계
- `npm test`: 27개 테스트 묶음 모두 통과 (2.10s 소요, 다국어/초성/카탈로그 무결성/복구 검증 완료).
- `npm run build`: TypeScript 컴파일, Vite 번들링, 3D 해부도 모델 패키징, 오프라인 셸 생성 모두 성공.
- 500회 연속 검색 벤치마크를 통해 14.26ms/op에서 0.75ms/op로 약 18.9배의 성능 개선을 직접 검증했습니다.
- APK 빌드와 배포 상태는 GitHub Actions 워크플로를 통해 확인합니다.

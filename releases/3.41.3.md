# v3.41.3

## 최신 업데이트 핵심 요약
- 운동 카드 상단을 종목명·진행률, 순서 변경·관리 버튼, 헬스장·머신 정보 구역으로 분리했습니다.
- 긴 종목명도 카드 너비를 사용하도록 바꾸고, 순서 변경 버튼과 나머지 관리 버튼 사이에 구분선을 추가했습니다.
- 메모는 별도 배경과 왼쪽 강조선으로 표시하고 운동 설정은 경계선과 배경으로 구분했습니다.
- 기존 번역 문구를 유지하며 8개 언어 팩을 그대로 사용합니다. 운동 ID와 기록, 브랜드 지정 방식은 변경하지 않습니다.

## 검증 및 한계
- `npm test`: 27개 테스트 묶음 통과.
- `npm run build`: TypeScript 검사, 웹 빌드, 모델 검증 및 오프라인 셸 생성 통과. 기존 큰 청크 경고는 남아 있습니다.
- 실제 Chrome에서 8개 언어 × 320·390px 너비의 제목 너비, 구역 분리, 가로 넘침을 확인하고 순서 이동·접기/펼치기 동작을 검증했습니다. 밝은/어두운 화면을 캡처해 확인했습니다.
- 실제 Android 기기에서의 터치 검증은 수행하지 않았습니다.
- APK 빌드와 배포 결과는 GitHub Actions에서 별도로 확인합니다.

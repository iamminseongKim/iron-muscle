# v3.30.0

## 최신 업데이트 핵심 요약
- 웹 오프라인 운동 모드: 필수 화면과 코드를 저장하여 준비 완료 후 인터넷 없이 재접속하고 운동을 기록할 수 있습니다. 새 버전은 모든 탭을 닫은 뒤 적용해 진행 중인 운동을 방해하지 않습니다.
- 루틴 레시피: 진행 중이거나 과거의 운동에서 종목 순서·반복수·휴식·좌우·묶음 구성을 저장하고 링크/JSON 파일로 공유합니다. 가져오기 미리보기와 새 운동 시작을 지원합니다. 무게·완료 여부·메모·신체 정보는 공유하지 않으며 새 운동의 무게는 0부터 입력합니다.
- 삭제 취소 및 30일 복구함: 운동 취소, 과거 기록 삭제, 종목·세트 삭제를 되돌릴 수 있습니다. 복구는 이후 수정한 기록을 보존하고 진행 중인 다른 운동을 덮어쓰지 않습니다.
- MY의 루틴/복구함 및 운동 화면의 바로가기를 추가하고 8개 언어에 신규 문구를 등록했습니다. 기존 JSON 백업에 루틴을 포함합니다.

## 검증 및 한계
- `npm test`: 기존 18개와 새 웹 기능 테스트를 포함한 19개 스위트 통과. 루틴 정보 최소화·입력 검증·백업·새 ID·목표 휴식, 복구 충돌·만료·저장 실패 롤백 검증.
- `npm run build`: TypeScript·Vite·모델 최적화·오프라인 캐시 생성 통과. 기존 대형 번들 경고 유지.
- 프로덕션 브라우저 네트워크 차단 검증: 오프라인 재접속, 공유 링크 미리보기, 루틴 시작, 삭제 취소, 취소한 세션의 새로고침 후 복구 및 320/390/768px 가로 넘침 점검.
- 누락된 홈 화면 아이콘을 추가하고 오프라인 필수 파일이 없으면 빌드가 실패하도록 검사합니다.
- 오프라인 재접속은 HTTPS 또는 localhost에서 최초 온라인 준비 완료 후 가능합니다. 처음 보는 대용량 3D 모델은 온라인 연결이 필요하며, 로컬 브라우저 데이터 삭제 또는 저장소 정리 시 파일 백업으로 복원해야 합니다.
- 공유 링크에는 루틴 이름과 사용자 종목 이름이 포함됩니다. 네이티브 앱은 파일 공유를 사용하며 자동 기기 간 동기화는 제공하지 않습니다. 복구함은 해당 기기의 임시 보관소이며 백업에는 포함하지 않습니다.
- 실제 모바일 기기의 저장소 회수 정책 및 홈 화면 설치 동작은 별도 확인이 필요합니다. iOS 산출물은 기존 방식의 미서명 IPA입니다.

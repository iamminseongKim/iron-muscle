# v3.39.0

## 최신 업데이트 핵심 요약
- 운동 시작 화면에서 AI가 작성한 JSON 또는 Markdown 표를 붙여넣어 종목과 세트 구성을 불러올 수 있습니다.
- 운동을 시작하기 전에 종목, 반복수, 무게, 단위, RPE, 템포, 메모, 편측·양측, 기구 유형과 핀로드·플레이트로드 구성을 확인합니다. 자동으로 연결하지 못한 종목은 사용자가 직접 선택합니다.
- 한팔·한발 종목도 기본은 양측을 묶어 기록합니다. 외부 AI용 질문은 좌우 분리 기록을 명시적으로 요청한 경우에만 편측과 좌우 세트를 사용하도록 안내합니다.
- 다국어 종목 이름과 별칭으로 기존 운동을 찾습니다. 기존 운동 ID와 기록을 유지하며 기구 브랜드를 자동 지정하지 않습니다.
- AI의 권장 휴식을 세트 완료 후 열리는 타이머의 기본값으로 사용합니다. 사용자가 조절할 수 있으며 실제 쉰 시간과 구분해 저장합니다.
- 첫 화면의 외부 AI용 질문 복사 버튼을 제공합니다. ChatGPT 등 외부 AI가 목표 부위·난이도·경험·기구·운동 시간을 대화로 확인한 뒤 최종 JSON을 출력하도록 요청합니다. 앱 안에서 AI를 호출하지 않습니다.
- 가져올 입력 형식과 예시를 제공합니다. 새 화면 문구를 8개 언어 팩에 등록합니다.

## 검증 및 한계
- `npm test`: 27개 테스트 묶음 통과. JSON과 Markdown 표, 다국어·사용자 종목 매칭, 미해결 종목 차단, 숫자 검증, RPE·템포·메모·편측·기구·권장 휴식 보존을 검증했습니다.
- `npm run build`: TypeScript, 웹 빌드, 모델 검증과 오프라인 셸 생성 통과. 기존 큰 청크 경고가 남아 있습니다.
- 실제 Chrome 클립보드 쓰기·읽기로 대화형 질문, 1회 운동 JSON 출력 조건과 양측 기본값을 확인했습니다. 첫 화면의 복사 버튼이 모바일 하단 메뉴에 가리지 않는 것도 검사했습니다.
- Chrome 모바일 화면 자동 검증으로 8개 언어와 가로 넘침, 오래된 미리보기 무효화, 진행 중·손상된 운동 보존, 저장소 읽기 실패 중단, 저장 결과와 권장 휴식 120초 타이머 연결을 확인했습니다.
- 실제 브라우저에서도 한국어 Markdown 운동 시작과 JSON 메타데이터 적용, RPE 7.5·템포 3-1-1·좌우·핀머신, 2분 타이머와 실제 쉰 시간 분리를 확인했습니다.
- 안내된 JSON과 Markdown 표 형식을 지원합니다. 임의의 자연어 설명을 해석하는 AI 호출은 포함하지 않습니다.
- 기존 공유 루틴과 완료된 운동 기록의 Markdown 복원 형식은 유지합니다.
- Android 실기기 검증은 수행하지 않았습니다. APK 빌드와 배포 상태는 GitHub Actions 결과로 확인합니다.

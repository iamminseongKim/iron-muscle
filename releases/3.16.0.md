### 🌟 최신 업데이트 핵심 요약

- **하루 운동 기록 하나로 합치기 (세션 병합 기능)**: 하루에 운동 세션이 2개 이상 기록되어 있을 때(오전/오후 2차 운동, 또는 오터치로 세션이 조기 완료되어 새로 시작한 경우), 기록 탭 상단의 **'기록 합치기'** 버튼을 통해 하나의 온전한 일지로 병합할 수 있습니다.
  - 모든 종목과 세트 기록, 중량, RPE, 템포가 손상 없이 순서대로 통합됩니다.
  - 동일한 종목(동일 ID 및 머신 브랜드)은 세트가 자연스럽게 이어붙여지며 세트 번호(1, 2, 3...)가 자동 재정렬됩니다.
  - 소요 시간(분)과 메모가 누락 없이 합산 보존됩니다.
- **운동 기록 수정 시 휴식 시간 편집 UX 고도화**:
  - `EditSessionModal` 내 종목별로 **[30s / 60s / 90s / 120s / 180s]** 퀵 칩 버튼을 제공하여, 클릭 한 번으로 해당 종목의 모든 세트에 휴식 시간을 일괄 적용할 수 있습니다.
  - 세트별 휴식 시간 입력 시 60초 이상일 경우 분/초(예: `1분 30초`)가 즉시 시각적으로 표시되어 직관성을 높였습니다.
  - 잘못 측정되거나 누락된 휴식 시간을 손쉽게 교정하여 AI 마크다운 분석 및 트레이닝 피드백의 정확도를 유지할 수 있습니다.

기존 운동 데이터 및 모든 사용자 기록은 100% 온전히 보존됩니다.

# v3.27.0

## 최신 업데이트 핵심 요약
- 내 헬스장 머신 브랜드에서 기타(직접 입력)를 선택하면 입력칸이 나타나며 입력한 브랜드를 저장하고 다시 수정할 수 있습니다.
- 하단 메뉴가 본문을 덮지 않도록 레이아웃을 분리했습니다. 화면 높이와 하단 안전 영역에 맞춰 본문이 스크롤되어 운동 시작 버튼을 누를 수 있습니다.
- 운동 추가, 탐색, 성장 지표 선택, 직접 등록에 머신·스미스·케이블·바벨·덤벨·맨몸·기타 분류를 통일했습니다. 헬스장 등록에는 머신·스미스·케이블 필터를 제공합니다.
- 기존 스미스 종목은 ID와 저장 기록을 바꾸지 않고 스미스 분류로 검색됩니다. 새 사용자 종목도 스미스로 등록할 수 있습니다.
- 스미스 분류명을 8개 언어 팩에 반영했습니다.

## 검증 및 한계
- npm test 및 npm run build 통과. 320×568, 360×640, 390×844, 430×932, 844×390, 768×1024 화면에서 하단 안전 영역 0/34px를 모사해 시작 버튼과 메뉴 비겹침을 확인했습니다. 브랜드 입력·저장·재열기·다른 머신 보존 및 스미스 선택 필터를 브라우저에서 확인했습니다.
- 실제 Android/iOS 기기별 키보드·시스템 제스처 영역은 실기기 검증이 필요합니다.

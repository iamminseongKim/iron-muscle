# 3.48.0

## 최신 업데이트 핵심 요약

- 묶음을 하나의 라운드 진행 버튼으로 실행합니다. ‘라운드 시작’ 후 ‘다음 종목으로’를 누르면 현재 종목 완료와 다음 종목 시작을 함께 저장하며, 마지막 종목을 마쳤을 때만 휴식합니다.
- 종목 사이의 휴식 타이머와 강제 피드백 입력을 제거했습니다. 피드백은 필요할 때 기록 수정에서 입력하며, 입력하지 않은 RPE를 만들지 않습니다.
- 묶기 전에 열었던 휴식 타이머도 현재 라운드 상태에 맞게 정리합니다.
- 기존 세트 번호가 서로 달라도 묶음 내 순서로 라운드를 연결합니다. 운동 ID, 세트 ID, 원래 번호와 완료 기록은 유지합니다.
- 종목 전환 시간을 라운드 휴식으로 표시하거나 휴식 목표와 비교하던 오류를 수정했습니다. 실제 휴식은 직전 세트 완료 후의 계획과 비교합니다.
- AI 분석용 내보내기에 묶음 종류·멤버 순서·라운드·종목 전환 시간·라운드 휴식을 구분해 포함합니다. 부위를 선택해도 함께 수행한 묶음 맥락을 유지합니다.
- 기존에 기록된 전환·휴식·타이머 값은 변경하지 않습니다. 근거가 불명확한 기록은 미확인으로 표시합니다.
- 새 문구를 8개 언어 팩에 반영합니다.
- 묶음 버튼을 빠르게 두 번 눌러 미수행 종목이 완료되는 일을 방지합니다.
- AI JSON에 `groups`와 종목별 `groupId`를 지원합니다. 공통 라운드·휴식·목표 RPE를 자동으로 적용하고 미리보기부터 실제 운동까지 묶음을 유지합니다.
- 그룹 ID·종목 수·라운드 수·휴식 충돌을 검증합니다. 목표 RPE는 묶음 기본값보다 종목 설정, 세트 설정 순으로 우선하며 실제 수행 RPE는 자동 입력하지 않습니다.
- AI 요청문과 형식 안내에 지원 스키마·우선순위·자동 묶음 예시를 추가했습니다. 일반 종목과 묶음을 함께 포함한 JSON 예시도 그대로 가져올 수 있습니다.

## 검증 범위와 한계

- `npm test`의 35개 테스트 묶음과 `npm run build`를 통과했습니다. 전환 시간을 휴식으로 오판하던 재현 사례, 과거 번호가 다른 묶음, 원본 기록 보존, 직전 세트의 휴식 목표와 8개 언어 AI 내보내기를 포함합니다.
- `scripts/test-guided-group-ui.mjs`로 컬·해머 컬 진행, 중간 타이머·피드백 없음, 라운드 휴식, 마지막 종료 확인, 기존 타이머 정리, 저장 실패 복구와 실제 포인터 중복 클릭을 검증했습니다.
- `scripts/test-group-workout-ui.mjs`와 `scripts/test-card-drag-ui.mjs`로 기존 묶음 화면·다국어·마우스·터치 정렬을 확인했습니다.
- `scripts/test-ai-group-import.mjs`와 `scripts/test-ai-group-import-ui.mjs`로 JSON 검증·공통 기본값·RPE 우선순위·8개 언어 미리보기·실제 라운드 진행·백업 보존을 확인했습니다.
- Android 실기기 검증과 외부 AI 서비스에 실제 요청을 보내는 검증은 포함하지 않았습니다. 앱에서 생성하는 요청문과 반환 JSON 처리, 분석용 내보내기 내용을 검증했습니다.

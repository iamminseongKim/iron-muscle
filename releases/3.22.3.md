# v3.22.3

## 최신 업데이트
- 운동 종목 선택 화면을 열 때 검색창에 자동으로 포커스하지 않아 모바일 키보드가 바로 뜨지 않습니다.
- 모바일 선택 화면을 가용 화면 전체로 넓히고, 검색창 입력 시 필터를 접어 키보드 위 결과 목록 공간을 확보했습니다. 필터는 버튼으로 다시 펼칠 수 있습니다.
- 검색 입력 글자를 16px로 조정하고 운동명 줄바꿈, 보조 정보 대비, 키보드 검색 키로 입력 종료를 개선했습니다.
- 필터 펼치기/접기 문구를 8개 언어에 추가하고 오늘 목표 부위 표시에도 번역을 적용했습니다.

## 검증
- npm test 및 npm run build 통과. 기존 대용량 번들 경고는 남아 있습니다.
- Chromium 모바일 390×844 및 키보드 높이를 모사한 390×440에서 자동 포커스 없음, 필터 접기/펼치기, 16px 입력 글자, 결과 영역 213px 확보, 검색 키로 포커스 해제, 종목 선택을 확인했습니다.
- 실제 iOS/Android 소프트 키보드와 기기 설치 검증은 수행하지 않았습니다. 화면 높이 축소 검증은 실제 키보드 테스트를 대체하지 않습니다.
- 기존 test-keyboard.mjs는 숫자 입력·스크롤·리사이즈 및 모달 포커스 검증을 통과한 뒤, 해부도 단계의 오래된 버튼 문구(근육 보기)를 찾지 못해 중단되었습니다.

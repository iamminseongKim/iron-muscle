# v3.38.1

## 최신 업데이트 핵심 요약
- 커스텀 운동 목록을 읽지 못한 상태에서 새 운동을 저장하거나 삭제하면 기존 데이터를 빈 목록으로 덮어쓸 수 있던 오류를 수정했습니다.
- 손상된 JSON, 목록이 아닌 데이터, 유효한 ID가 없는 항목 또는 저장소 읽기 실패가 있으면 변경을 중단하고 원본 데이터를 보존합니다.
- 정상 목록의 추가·수정·삭제와 기존 운동 ID, 이름, 근육 정보 및 사용자 기록을 유지합니다. 사용자 화면 문구와 운동·근육 명칭 변경이 없어 언어 팩 변경은 없습니다.

## 검증 및 한계
- pstack의 `tdd` 지침에 따라 수정 전 회귀 테스트가 `Unreadable custom data must block saves`로 실패하는 것을 확인한 뒤 수정했습니다.
- `npm test`: 26개 테스트 묶음 통과. 손상 데이터와 저장소 읽기 실패 시 원본 보존 및 성공 이벤트 미발행, 정상 추가·수정·삭제를 검증했습니다.
- `npm run build`: TypeScript 검사, 웹 빌드, 모델 검증 및 오프라인 셸 생성 통과. 기존 큰 청크 경고는 남아 있습니다.
- 보존한 손상 데이터를 자동 복구하는 기능은 포함하지 않습니다. Android 실기기에서 저장소 손상을 직접 재현하지 않았습니다.
- Android APK 컴파일과 배포는 GitHub Actions에서 확인합니다.

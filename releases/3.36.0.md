# v3.36.0

## 최신 업데이트 핵심 요약
- Android 앱의 마이 화면에 앱 업데이트 영역을 추가했습니다. 화면을 열거나 업데이트 확인을 누르면 GitHub의 최신 정식 릴리즈 버전과 변경 내용을 확인합니다.
- 현재 앱보다 새 버전이 있고 APK가 준비되었으면 웹사이트 방문 없이 Android 시스템 다운로드로 설치 파일을 받습니다. 완료 알림에서 APK를 열고 Android 확인 화면을 거쳐 업데이트로 설치합니다.
- 통신 실패 시 재시도할 수 있고, 설치 파일이 준비되지 않은 릴리즈는 다운로드 버튼 대신 안내를 표시합니다. 정식 SemVer 버전만 비교하고 이 저장소의 해당 버전 APK 주소만 허용합니다.
- 업데이트 화면 문구를 8개 언어 팩에 등록했습니다. 운동 ID와 사용자 기록은 변경하지 않습니다.
- 배포 대상을 Android로 정리했습니다. GitHub Actions의 iOS 빌드와 IPA 배포를 제거했습니다.

## 검증 및 한계
- `npm test`: 24개 테스트 묶음 통과. `npm run build` 통과(큰 청크 크기 경고 포함). 업데이트 버전 비교·APK 주소 검증 테스트를 전체 테스트에 포함했습니다.
- 모의 Android 환경의 390px 브라우저 화면에서 새 버전 표시와 APK 다운로드 버튼을 확인했습니다.
- Android 실제 기기에서 다운로드 완료 알림, APK 열기, 설치 권한 및 기존 서명 앱 위에 업데이트하는 과정은 로컬에서 검증하지 못했습니다. 다운로드 시작은 설치 완료를 의미하지 않습니다.
- 자동 설치나 백그라운드 업데이트 알림은 제공하지 않습니다. 앱 업데이트 영역을 열 때 최신 릴리즈를 확인합니다.

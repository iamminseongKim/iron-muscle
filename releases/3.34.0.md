# v3.34.0

## 최신 업데이트 핵심 요약
- MY → 앱 설정에서 강조 색상을 보라색 또는 초록색으로 선택할 수 있습니다. 새 설치의 기본 강조 색상은 보라색이며 선택한 색은 기기에 저장됩니다.
- 운동 시작·진행, 종목 탐색, 기록, 통계, 모달과 하단 독바의 강조색을 선택한 색상에 맞춰 표시합니다. 라이트·다크 모드 모두에 적용됩니다.
- 색상 설정 문구를 8개 언어 팩에 반영했습니다. 기존 운동 기록과 운동 ID는 변경하지 않았습니다.

## 검증 및 한계
- `npm test`에 해당하는 19개 테스트 묶음과 `npm run build`에 해당하는 TypeScript·Vite·모델 압축 검증을 통과했습니다. 이 환경에 npm 명령이 없어 번들 Node로 같은 스크립트를 직접 실행했습니다.
- 브라우저에서 색상 변경과 재시작 후 설정 유지 여부를 확인했습니다.
- 실제 Android·iOS 앱 설치와 스토어 배포는 이 검증에 포함되지 않습니다.

# v3.23.1

## 최신 업데이트 핵심 요약
- 운동 선택 기본 목록을 내 완료 기록·대표 종목·사용자 등록 종목으로 정리하고 전체 보기 전환을 제공합니다.
- 정확한 이름·별칭·8개 언어 번역을 최우선으로 검색합니다. 같은 관련도에서 최근 기록과 대표 종목을 우선하며, 부위·장비 조합 검색과 명시적 필터 유지도 지원합니다.
- 덤벨 루마니안 데드리프트, 스미스머신 루마니안 데드리프트, 시티드 케이블 플라이를 추가해 총 1,035종을 제공합니다.
- 데드버그 이름·코어 분류와 EZ바 스컬 크러셔의 팔 분류를 수정했습니다. 기존 ID와 운동 기록은 유지합니다.
- 릴리즈 노트의 필수 요약 제목을 수정해 모바일 배포의 노트 생성 오류를 해결했습니다. v3.23.0의 검색 개선을 포함하는 후속 패치입니다.

## 검증 및 한계
- npm test, npm run build, 모바일 검색 UI 검증 및 릴리즈 노트 생성 검증을 통과했습니다.
- 390×844 대표/전체 목록 전환, 390×440 어두운 화면, 부위 필터 유지·전체 검색 복구, 신규 종목 선택을 확인했습니다.
- 대표 종목은 편집 기준이며 전체 사용자 인기 통계가 아닙니다. 기록은 기기 내부에서만 활용합니다.
- 전체 기존 종목 설명의 재검수, 오타 유사 검색, 중복 기록 자동 통합은 포함하지 않습니다. 실제 iOS/Android 키보드·설치 검증은 수행하지 않았습니다.
- 기존 대용량 번들 경고는 남아 있습니다. 추가 근거와 유지 지침은 docs/exercise-discovery.md에 기록했습니다.

# v3.33.0

## 최신 업데이트 핵심 요약
- 운동 시작, 운동 카드, 종목 탐색, 기록, 통계, MY 화면을 흰 바탕과 둥근 연회색 카드 중심으로 정리했습니다. 투명 플로팅 하단 독바는 유지했습니다.
- 운동 시작 화면의 중복된 루틴 레시피·복구함 바로가기를 제거했습니다. 두 기능은 MY 화면에서 계속 사용할 수 있습니다.
- 컨디션과 운동 정보에 표시하던 이모지를 아이콘 또는 일반 문구로 바꾸고, 언어 선택의 국기는 언어 코드로 바꿨습니다. 기존 컨디션 저장 값과 운동 기록은 변경하지 않았고, 새 문구는 8개 언어 팩에 반영했습니다.

## 검증 및 한계
- `npm test`의 19개 테스트 묶음과 `npm run build` 통과.
- Chrome UI 검증에서 320·390·768px 화면, 운동 시작·진행·종목 선택, 다크 모드, 하단 독바, 8개 언어 전환과 가로 넘침·페이지 오류를 확인했습니다.
- 실제 Android·iOS 앱 설치와 스토어 배포는 이 검증에 포함되지 않습니다.

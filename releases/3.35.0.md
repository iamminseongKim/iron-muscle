# v3.35.0

## 최신 업데이트 핵심 요약
- 지난 운동을 선택해 종목·중량·횟수·기구 설정을 새 운동으로 가져올 수 있습니다. 완료 세트만 재사용하며 ID와 시작 시간을 새로 만들고 메모·실제 휴식·RPE·완료 상태는 초기화합니다. 하나만 남은 그룹은 해제합니다.
- 진행 중 종목을 위·아래로 이동할 수 있습니다. 슈퍼세트 등 묶인 종목은 함께 이동하며 기존 세트와 기록 ID를 보존합니다.
- 운동 완료 팝업을 요약 화면으로 바꾸었습니다. 완료 세트·반복수·시간·볼륨, 같은 기구·수행 조건의 지난 운동 대비 변화, 최고 중량 경신과 오늘 기록 복사를 제공합니다. 맨몸·보조 운동은 최고 중량 경신 대상에서 제외합니다.
- 이전 중량과 피로도 분석이 오래된 기록을 참조하던 오류를 수정했습니다. 미지정 기구에 등록 머신의 중량을 임의로 가져오지 않으며, RPE 기록이 부족하면 데이터 부족으로 표시합니다.
- 어시스티드 운동의 음수 보조 중량을 JSON 백업·복원할 수 있습니다. 복원 실패 시 헬스장 설정도 되돌립니다.
- 운동 완료 저장과 진행 세션 제거를 함께 검증하고 실패 시 원래 데이터를 복원합니다. 잦은 세트 수정 중 타이머가 멈추거나 일시정지 시간을 완료 시 다시 더하던 문제와 복사 실패를 성공으로 표시하던 문제도 수정했습니다.
- 새 UI 문구를 8개 언어 팩에 반영했습니다. 기존 운동 ID와 사용자 기록, 브랜드 미지정 상태를 유지합니다.

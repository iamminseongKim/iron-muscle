# v3.41.1

## 최신 업데이트 핵심 요약
- AI 루틴 가져오기 화면에서 불필요한 예시 넣기 버튼(JSON 예시 넣기, Markdown 예시 넣기)을 제거하여 입력 화면을 간소화했습니다.
- 입력창 내용이 있을 때 원터치로 비울 수 있는 '전체 삭제' 버튼을 입력 라벨 우측 및 하단 액션 바에 추가했습니다.
- 기존의 생소했던 '구성 확인' 버튼 명칭을 '운동 시작'으로 변경하여 루틴 확인 및 시작으로 이어지는 사용자 흐름을 자연스럽게 일원화했습니다.
- AI 루틴 입력창에 고정폭 글꼴(`font-mono`), 줄 높이 개선, 모바일 스마트 구두점/자동 대문자 비활성화(`spellCheck={false} autoCapitalize="none" autoCorrect="off"`)를 적용하여 JSON 및 Markdown 직접 수정 경험을 개선했습니다.
- 신규 UI 문구('운동 시작', '전체 삭제', '루틴 구성 확인')를 8개 언어(한국어, 영어, 일본어, 중국어 간체/번체, 스페인어, 프랑스어, 독일어) 언어 팩에 모두 등록했습니다.

## 검증 및 한계
- `npm test`: 27개 테스트 묶음 모두 통과. AI 루틴 파서, 포맷 검증, 커스텀 운동 연동, 8개 언어 UI 키 누락 검증을 통과했습니다.
- `npm run build`: TypeScript 컴파일, Vite 번들링, 3D 해부도 모델 패키징, 오프라인 셸 생성 모두 성공.
- 입력 초기화 시 기존 검색 쿼리 및 커스텀 등록 임시 상태도 안전하게 리셋됩니다.
- 모바일 가상 키보드 환경에서의 실기기 E2E는 GitHub Actions 빌드 산출물과 브라우저 테스트를 통해 확인합니다.

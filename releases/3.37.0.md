# v3.37.0

## 최신 업데이트 핵심 요약
- 복구함을 운동 기록별 카드로 묶어 같은 루틴 제목과 날짜가 항목마다 반복되던 화면을 정리했습니다. 삭제한 세트의 번호·중량·횟수, 삭제 시간과 남은 보관 기간을 바로 확인할 수 있습니다.
- 검색, 항목·그룹·전체 선택과 선택 복원·선택 삭제를 추가했습니다. 복구함 비우기로 여러 항목을 한 번에 정리할 수 있습니다.
- 영구 삭제 전 대상과 개수를 보여주는 확인 화면을 제공합니다. 확인 화면을 연 뒤 새로 들어온 항목은 삭제하지 않으며, 저장된 운동 기록은 유지됩니다.
- 여러 항목 복원은 하나의 저장 작업으로 처리합니다. 선택한 항목만 복원하며 기존 수정값과 세트 ID·순서·진행 시간을 보존하고, 활성 운동 충돌이나 저장 실패 시 부분 복원을 막습니다.
- 복구함의 신규 문구를 8개 언어 팩에 반영했습니다. 기존 기록과 30일 보관 정책, 삭제 직후 실행 취소 기능을 유지합니다.

## 검증 및 한계
- `npm test`: 일괄 복원·선택 삭제·전체 비우기·충돌·손상 데이터·저장 실패 회귀를 포함한 25개 테스트 묶음 통과.
- `npm run build`: TypeScript 검사, 웹 빌드, 모델 검증, 오프라인 셸 생성 통과. 기존 큰 청크 크기 경고는 남아 있습니다.
- 모바일 Chrome에서 선택·검색·단일/선택/전체 삭제 확인·취소·복원·저장 실패·새 항목 보존과 320/390/768px, 8개 언어, 다크 모드 화면을 검증했습니다.
- Android 실기기에서의 설치·실행은 직접 검증하지 않았습니다. 로컬 저장소가 삭제되면 복구함도 삭제되며 서버 백업은 추가하지 않았습니다.

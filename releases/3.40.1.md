# v3.40.1

## 최신 업데이트 핵심 요약
- 외부 AI가 추천한 `Reverse Pec Deck`을 기존 리버스 펙덱 플라이 종목에 연결할 때 가슴·측면 삼각근으로 잘못 분류되던 데이터를 어깨·후면 삼각근으로 수정했습니다. 동작 분류도 후면 삼각근 동작으로 맞췄습니다.
- 기존 운동 ID와 종목 이름, 세트 및 사용자 기록은 유지합니다. 이 종목의 해부도와 근육별 집계는 수정된 분류를 사용합니다.
- 기존 8개 언어의 종목명과 `deltoid_rear` 근육 번역을 그대로 사용합니다. 신규 문구·종목·근육 ID 추가는 없습니다.

## 검증 및 한계
- 분류 근거는 [Life Fitness Optima 사용자 설명서 11쪽](https://www.lifefitness.com.au/wp-content/uploads/2015/02/Optima_user_manual_for_all_strength_2_585_1371787541.pdf)의 Rear Deltoid 동작 설명입니다.
- 수정 전 회귀 테스트가 실제 가슴 분류와 예상 어깨 분류의 불일치로 실패하는 것을 확인했습니다. 수정 후 영어 이름 가져오기와 완료 세트의 후면 삼각근 집계가 통과했습니다.
- 사용자 예시의 영어 종목 6개를 검증했습니다. 5개는 기존 ID와 연결되고, 형태가 특정되지 않은 `Leg Curl`은 미확정 상태를 유지합니다.
- `npm test`: 27개 테스트 묶음 통과. `npm run build`: TypeScript, 웹 빌드, 모델 검증과 오프라인 셸 생성 통과. 기존 큰 청크 경고가 남아 있습니다.
- 사용자 정의 운동의 근육 정보를 덮어쓰지 않습니다. 다른 종목 전체를 해부학적으로 재검토한 변경은 아닙니다.
- Android 실기기 검증은 수행하지 않았습니다. APK 빌드와 배포 상태는 GitHub Actions 결과로 확인합니다.

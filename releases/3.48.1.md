# 3.48.1

## 최신 업데이트 핵심 요약

- Android에서 큰 운동 기록을 내보낼 때 앱이 종료될 수 있는 오류를 수정했습니다. Markdown 일지와 JSON 백업은 Android 저장 창에서 파일로 저장합니다.
- Android 저장 창을 열 수 없거나 파일 저장에 실패하면 실패 안내를 표시합니다. 백업 화면에서는 복사할 수 있도록 내보낼 텍스트를 제공합니다.

## 검증 범위와 한계

- `npm test`와 `npm run build`를 통과했습니다.
- JVM 검사에서 큰 Markdown 일지의 저장 상태 크기와 저장한 파일의 바이트를 확인했습니다. 저장 창 취소, 중복 호출, 저장 창 실행 실패, 이전 Android 버전의 PNG 저장 경로도 검사했습니다. Android 실기기 검증은 포함하지 않았습니다.

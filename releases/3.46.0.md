# 3.46.0

## 최신 업데이트 핵심 요약

- 마이 탭 맨 위에 획득한 배지와 전체 컬렉션을 추가했습니다. 배지를 누르면 실제 취득일, 달성 조건, 진행도와 근거 운동 기록을 확인합니다.
- 첫 운동, 누적 운동 10·30·50·100·200·365일, 주 2일 이상 4·8·12주 연속 운동, 30일 이상 쉬고 복귀, 개인 최고 중량 및 스쿼트·벤치프레스·데드리프트 PR 등 배지 16개를 제공합니다.
- 누적 운동은 스타터·브론즈·실버·골드·플래티넘·다이아몬드·엘리트의 7단계로 표시합니다. 단계별 색과 형태, 큰 달성 숫자를 사용하는 벡터 배지와 현재 단계·다음 목표를 제공합니다.
- 운동 완료 화면에는 이번 운동으로 처음 획득한 배지만 표시합니다. 과거 기록도 실제 달성일로 소급 인정하며 기록 수정·삭제·백업 복원 후 다시 계산합니다.
- PR은 기존과 같은 종목·장비·수행 조건에서의 최고 수행 중량입니다. kg와 lb를 변환하며 첫 기록, 워밍업과 활성화 세트는 PR에서 제외합니다. 3대 배지는 해당 바벨 종목만 인정합니다. 실제 1RM 인증이나 추정 1RM 합계 배지는 아닙니다.
- 새 문구는 8개 언어에 반영했습니다. 기존 운동 ID와 사용자 기록, 백업 형식은 보존합니다.

## 판정 기준

- 완료한 유효 세트가 있는 운동을 인정합니다. 같은 날짜의 여러 운동은 누적 운동일 1일로 계산합니다.
- 꾸준함은 월요일부터 일요일까지 주 2일 이상 운동한 연속 주를 셉니다. 진행도는 과거 최장 연속 기록이며 취득일은 조건을 처음 충족한 날입니다.
- PR 배지의 최초 취득일과 당시 중량을 보존해 표시하고, 갱신 횟수는 현재 운동 이력을 기준으로 계산합니다.

## 검증

- 배지 판정과 기존 PR·운동 흐름의 단위 테스트를 통과했습니다. 같은 시각에 저장된 대소문자 ID의 PR 비교 회귀를 포함합니다.
- Chrome에서 마이 탭 상단 배치, 취득일·근거 중량, 빈 상태, 포커스 복구, 320·390·768px의 밝은·어두운 화면, 8개 언어, 기록 보존, 실제 백업 복원과 완료 시 신규 배지 안내를 확인했습니다.
- 단계별 벡터 디자인을 반영한 실제 제품 빌드에서도 7단계의 서로 다른 색상과 단계 표시, 다음 목표와 최고 단계의 동작을 확인했습니다.
- `npm test` 전체 32개 테스트 묶음과 `npm run build`의 TypeScript·웹 빌드·모델 검증·오프라인 셸 생성이 통과했습니다. 기존 큰 청크 경고는 남아 있습니다.
- 기존 운동 흐름 UI 스크립트의 오래된 버튼명을 현재 화면에 맞췄습니다. Chrome에서 운동 재시작·순서 변경·완료 저장·PR·8개 언어 회귀 검증이 통과했습니다.

## 한계

- 실제 Android 기기에서는 확인하지 않았습니다.
- 기록을 수정하거나 삭제하면 해당 기록에 의존한 배지와 취득일도 바뀔 수 있습니다. 별도의 영구 업적 원장은 저장하지 않습니다.
- 사용자 입력 기록을 기준으로 판정하며 운동 수행이나 중량을 외부에서 인증하지 않습니다.

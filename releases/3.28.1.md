# v3.28.1

## 최신 업데이트 핵심 요약
- **운동 탐색 시 특정 근육 선택에 따른 주동근 최우선 정렬 개선**:
  - 3D 해부학 모델 또는 근육 필터에서 특정 부위(예: 상완삼두근)를 선택했을 때, 해당 근육이 '주동근'인 종목(케이블 푸시다운, 스컬 크러셔, 딥스 등)이 '협응근'인 종목(벤치프레스, 숄더프레스 등)보다 무조건 최상단에 먼저 노출되도록 정렬 우선순위를 개편했습니다.
  - 선택한 부위를 집중적으로 훈련하기 위한 종목을 바로 확인할 수 있으며, 그 뒤에 해당 부위가 협응근으로 보조하는 복합 운동이 자연스럽게 이어집니다.
- **운동 탐색 랭킹 회귀 테스트 추가**:
  - `test-exercise-discovery.mjs`에 근육 필터 시 주동근 우선 정렬 무결성 검증 추가.

## 검증 및 한계
- 로컬 17개 회귀 테스트(`npm test`) 및 프로덕션 빌드(`npm run build`)를 모두 통과했습니다.
- Android APK/iOS 산출물 빌드는 GitHub Actions v3.28.1 워크플로를 통해 빌드 및 배포됩니다.

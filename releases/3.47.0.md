# 3.47.0

## 최신 업데이트 핵심 요약

- 슈퍼세트·컴파운드세트·자이언트세트를 하나의 라운드 카드로 표시합니다. 현재 라운드의 종목·중량·횟수·진행 버튼을 먼저 보여주고 전체 세트와 상세 설정은 펼쳐서 확인합니다.
- 묶음의 라운드 수와 휴식 시간을 명시적으로 함께 적용할 수 있습니다. 종목별 중량·반복수·단위·세트 종류는 독립적으로 유지하며, 완료한 세트와 진행 중인 세트는 보존합니다.
- 종목별 현재 중량과 반복수를 남은 라운드에 적용할 수 있습니다. 종목 종료 피드백은 기본으로 접어 표시합니다.
- 세트 진행 중이나 휴식 중에는 다른 세트를 시작할 수 없습니다. 휴식 타이머를 최소화하거나 새로고침한 뒤에도 제한을 유지하며, 휴식을 명시적으로 종료하면 해제합니다.
- 같은 묶음의 같은 라운드에서는 다음 종목으로 이어지고, 라운드를 마친 뒤 휴식합니다.
- 전체 예정 세트를 모두 마치면 휴식 타이머 대신 ‘운동을 마치겠습니까?’를 표시합니다. ‘계속 기록하기’로 세트를 추가할 수 있고, ‘운동 마치기’는 최신 기록을 저장합니다.
- 변경 문구를 8개 언어 팩에 반영합니다.

## 검증 범위와 한계

- `npm test`의 33개 테스트 묶음과 `npm run build`를 통과했습니다. 묶음 완료 후 전환, 진행·휴식 시작 제한, 완료·진행 중 기록 보존, 독립 단위, 새 라운드 ID를 확인했습니다.
- `scripts/test-group-workout-ui.mjs`로 모바일 Chrome에서 묶음 화면과 휴식 최소화·새로고침, 마지막 세트 종료 확인, 저장 실패 복구, 완료 기록의 피드백 수정, 최신 라운드 설정과 전체 접기를 검증했습니다. 8개 언어의 320px 화면도 확인했습니다.
- `scripts/test-card-drag-ui.mjs`로 마우스·터치 정렬과 묶음 단위 이동을 확인했습니다.
- Android 실기기 검증은 포함하지 않습니다. APK 배포 여부는 GitHub Actions와 실제 릴리즈 첨부 파일로 확인합니다.

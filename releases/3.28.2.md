# v3.28.2

## 최신 업데이트 핵심 요약
- **3D 해부학 모델링 후면(등·기립근) 클릭 시 복직근이 잘못 선택되는 버그 수정**:
  - 후면 뷰(등, 허리, 기립근 부근)에서 광선(Raycaster)이 몸통을 관통했을 때 앞쪽 복직근이 우선 판정되어 선택되던 문제를 해결했습니다.
  - 카메라 시점(전면/후면)을 정확히 판별하여, 후면 뷰에서는 터치한 등 쪽의 표면 근육(척추기립근 erectors, 광배근 lats 등)이 최우선으로 정확하게 선택됩니다.

## 검증 및 한계
- 로컬 17개 회귀 테스트(`npm test`) 및 프로덕션 빌드(`npm run build`)를 모두 통과했습니다.
- Android APK/iOS 산출물 빌드는 GitHub Actions v3.28.2 워크플로를 통해 빌드 및 배포됩니다.

# v3.31.0

## 최신 업데이트 핵심 요약
- 운동 인증 이미지에서 종목이 많을수록 종목명과 세트 정보의 글자 크기 및 행 간격을 단계적으로 줄여 세로 길이를 단축합니다. 모든 종목과 세트 정보는 계속 표시합니다.
- 15종목 예시 카드는 1080 × 2045px로 생성되어 기존 약 3090px 높이보다 짧아졌습니다. 긴 종목명과 여러 줄 정보가 있으면 필요한 만큼 높이가 늘어납니다.

## 검증 및 한계
- `npm test`, `npm run build` 통과.
- 실제 Chrome 캔버스에서 15종목 카드의 전체 종목명 표시, 텍스트 가로 경계, 8개 언어의 기존 카드 렌더링을 확인했습니다.
- 인스타그램 화면별 표시 방식과 실제 모바일 기기 공유 결과는 별도 확인이 필요합니다.

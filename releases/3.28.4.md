# Iron Muscle Tracker 3.28.4

## 최신 업데이트 핵심 요약
- **GitHub Actions CI/CD 파이프라인 원복 및 최적화**:
  - `build-web` 직렬 대기로 인해 전체 빌드 시간이 지연되던 문제를 해결하기 위해, Android APK 및 iOS IPA 빌드가 워크플로 시작과 동시에 병렬로 즉시 시작되도록 원복했습니다.
  - 불필요한 직렬 대기(35초) 및 아티팩트 다운로드 오버헤드를 제거하여 임계 경로(Wall-clock time)를 단축했습니다.
  - 동일 커밋/태그에 대한 중복 실행 방지(`concurrency`) 및 17개 단위 테스트 병렬 실행 스크립트는 유지됩니다.

## 검증 범위 및 한계
- 로컬 `npm test` 병렬 실행 정상 통과 및 `npm run build` 검증 완료.
- GitHub Actions 클라우드 환경에서 Android/iOS 즉시 병렬 빌드 및 릴리즈 배포 완료 검증.

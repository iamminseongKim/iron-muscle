# 3.46.2

## 최신 업데이트 핵심 요약

- AI 루틴 입력을 전체 삭제하거나 마지막 글자를 지워도 입력 영역을 유지합니다. 전체 삭제 후 입력란으로 초점을 돌립니다.
- 원문을 수정하기 전까지 루틴 미리보기의 종목 선택을 보존합니다. 운동 시작 전 다른 탭을 확인해도 입력 내용과 선택이 유지됩니다.
- 미리보기를 여는 버튼을 ‘루틴 확인’으로 구분합니다.
- 백업 내용을 수정하거나 파일 확인에 실패하면 이전 복원 미리보기를 해제합니다. 늦게 끝난 파일 읽기가 새 입력을 덮어쓰지 않도록 처리합니다.
- 종목 검색의 필터 초기화에 ‘내 헬스장’ 조건을 포함합니다.
- 이미 저장한 루틴은 ‘저장됨’으로 표시하고 반복 저장으로 복사본이 생기지 않도록 합니다.
- 변경한 UI 문구를 8개 언어 팩에 반영합니다.

## 검증 범위와 한계

- `npm test`의 32개 테스트 묶음과 `npm run build`를 통과했습니다.
- `node scripts/test-ux-flow-ui.mjs`로 모바일 크기의 격리된 Chrome에서 입력 삭제, 미리보기 재진입, 탭 전환, 백업 검증, 루틴 저장, 필터 초기화를 확인했습니다. 백업 파일 읽기 실패와 늦게 끝난 읽기 결과의 무효화도 검증했습니다.
- 탭 전환 중 초안을 보존합니다. 새로고침이나 앱 종료 후 초안 복구는 포함하지 않습니다.
- Android 실기기 검증은 포함하지 않습니다. APK 배포 여부는 GitHub Actions와 릴리즈 첨부 파일을 기준으로 확인합니다.

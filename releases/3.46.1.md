# 3.46.1

## 최신 업데이트 핵심 요약

- 슈퍼세트와 컴파운드세트의 같은 라운드에 휴식 시간을 함께 표시합니다. 타이머에서 휴식을 종료하고 저장하면 운동을 다시 열어도 표시가 유지됩니다.
- 새 운동 묶음은 운동 목록에서 붙여 배치합니다. 색상 연결선과 묶음 내 순서를 추가했습니다.
- 등록한 머신을 목록 위에 표시합니다. 머신 이름이나 수정 버튼을 누르면 설정이 열리며 직접 입력한 브랜드도 저장할 수 있습니다.
- 운동 카드 하단의 중량 증가 단위 입력을 제거했습니다. 저장된 증가 단위는 운동 제안에 계속 사용합니다.
- 공유 카드와 백업 미리보기에서 lb를 kg으로 환산해 합산합니다. 완료한 드롭세트의 각 구간도 포함합니다.
- 세션 기본 단위로 기록한 과거 운동을 운동 카드에서도 해당 단위로 표시합니다.

## 검증 범위

- 같은 라운드의 휴식 표시와 재로딩, 혼합 단위 및 드롭세트 합산은 회귀 테스트로 확인합니다.
- Android 실기기 검증은 포함하지 않았습니다.

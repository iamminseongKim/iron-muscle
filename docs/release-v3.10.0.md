# v3.10.0 — 사용자 종목 이름 보존과 머신 라이브러리 확장

직접 등록한 운동을 저장한 뒤 기록 조회와 Markdown에서는 `운동 종목`, 통계에서는 내부 ID로 보여 주던 문제를 수정했습니다. 모든 기록 화면과 종목 묶기에서 사용자 종목을 포함한 공통 조회 함수를 사용합니다.

- 새 운동 기록에 종목명을 함께 저장합니다. 기존 기록도 사용자 종목 정보가 남아 있으면 읽을 때 이름을 보충하고, 다음 저장 시 함께 보존합니다.
- 사용자 종목 저장에 실패하면 등록을 완료하지 않고 입력을 유지합니다.
- 종목 ID, 세트, 브랜드, kg/lbs 단위는 유지합니다. 이미 사용자 종목 정보와 이름이 모두 없어진 기록은 다른 운동으로 추측해 바꾸지 않습니다.
- 머신 95 → 121개, 전체 종목 903 → 929개. 이두·삼두·전완·등·어깨·가슴·하체·힙·코어의 머신 동작을 추가했습니다.
- 기존 `Machine_Bicep_Curl` ID를 유지하면서 이름을 `암컬 머신 (바이셉 컬)`로 개선하고 암컬·이두 컬·Arm Curl 등의 검색 별칭과 한국어 사용 안내를 추가했습니다.
- 제조사별 동일 동작을 중복 등록하지 않고, 동작 또는 기구 구조가 다른 항목을 수록했습니다. 근거는 [종목 출처](exercise-sources.md#v3100-머신-확장)에 정리했습니다.

검증: 회귀 테스트, 사용자 종목 저장/재조회/백업/저장 실패 테스트, 프로덕션 빌드, 390px 모바일 화면에서 기록·통계·Markdown 표시와 재시작 후 이름 보존 확인.

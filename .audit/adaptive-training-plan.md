## Definition of done

Imported prescriptions never populate actual RPE or actual rest. Old values and identifiers survive load, backup, and save. Each set has explicit type, nullable actual feedback, independent completion, start and completion events. The UI can complete, undo, edit, recover, and accept or reject next-set suggestions. Exports distinguish plans, measured performance, estimates, and unknown legacy provenance. All eight language packs cover new text. npm test and npm run build pass. Commit and higher SemVer tag are pushed and Actions and APK status are reported truthfully.

## User feedback applied

- Manual workouts do not receive artificial prescriptions from input defaults. Missing target RPE is hidden.
- The RPE slider follows continuous pointer movement locally, then saves one 0.5-step value on release. A short reserve-repetition explanation accompanies it.
- Long-press ordering supports mouse and touch, preserves grouped exercises, and avoids input controls and ordinary scrolling.
- A labelled primary set control replaces ambiguous icons. The shared progression model permits one active set and requires earlier pending sets to finish first. Starting can be cancelled in set options.
- Independent review corrected legacy feedback reopening and completed-edit skip data loss. Cross-family review was unavailable in this harness.

Local acceptance passed. GitHub Actions and APK publication are checked after the tag is pushed and reported in the chat. Native device behavior and v3 Markdown reimport remain the documented limitations.
